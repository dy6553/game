# 4점사·바주카와 전투 HUD

2026-11-08 사용자 요청. 사진은 아이폰 사격 때 화면이 이상하다는 제보와 맵 요구이며, 사용자는 갤럭시여서 정확한 아이폰 증상은 알지 못한다고 답했다. 아래 수치는 제시 후 사용자가 ‘추천 수치로 진행’ 승인했다.

## 새 무기

- 4점사 소총: 한 번 누르면4발, 발당15 피해,32발 탄창. 점사 내부0.08초, 점사 시작 간격0.75초, 재장전2.2초. 누른 채로 무한 점사하지 않는다. 사망/무기교체/재장전은 잔여 점사를 취소한다.
- 바주카: 한 발 장전, 재장전3초, 직격100 피해. 로켓은24m/s로 직진하고 벽·문·바닥·캐릭터에 닿으면 폭발한다. 최장5초 비행. 폭발 반경5m, 최대100에서 거리 비례 감소. 가까운 자기 폭발 피해 적용, 벽/층 바닥 차폐·부활 보호·팀 아군 피해 차단 적용. 지형 앞에서 발사하면 지형에 맞으며 벽을 뚫어 상대를 맞히지 않는다.
- 봇전 전용 기존 강화는 새 무기에도 적용, 온라인 성능은 기본값. 시작 선택·보급·로비 손 모델·1인칭 모델·재장전·탄약·합성 소리 연결. 바주카는 발사 때 탄약을 소비하고 비행 후 실제 충돌 때 서버가 피해/처치를 정한다.
- 무기9종+장비3종으로 매판 랜덤 상자는12개. 실내1/2층 포함·옥상 제외·같은 위치20초 재보급·각 장비2개/총3칸 규칙 유지.
- 표적의 실제 월드 좌표를 장비/로켓/체력 HUD에 공유한다. 이전 표적 루트 노드 원점 대신 표적 본체 위치를 사용한다.

## 전투 화면

왼쪽 미니맵, 구분된 ‘내 체력’ 큰 숫자/초록 막대, 위 중앙 경기 점수와 상황, 오른쪽 총 이름/큰 탄약/재장전 정보를 표시한다. 조준한 살아 있는 적은 중앙 위 ‘적 이름+체력 숫자/붉은 막대’로 표시한다. 시야를 벗어나거나 벽 뒤로 숨거나 사망하면 적 체력 카드는 숨긴다. 예전 긴 체력 문장과 봇3명 상세 점수는 화면에서 숨기고 중복 정보를 줄였다. 기존 모바일 스틱·발사/점프 버튼 크기는 유지한다.

미니맵은 실제 항구/폐공장 건물과 출입 가능 건물, 북쪽, 나의 위치/방향, 아군, 현재 시야에 보이는 적을 표시한다. 벽 뒤 적을 미니맵으로 추적하지 않는다. 지도/체력 갱신은10Hz이며 지도 전용2D 캔버스를 사용해3D 렌더를 추가하지 않는다. 메뉴/홈/결과/선택창에서 전투 카드를 숨긴다.

## 사격 화면 안정화

온라인 총구 효과의 시작점이 카메라 위치인 경로가 있었다. 카메라0.5m 이내에서 총구 평면 섬광을 생성하지 않도록 실제 실패 검사 후 수정했다. 사격 효과 ‘안정’ 설정은 총구 섬광/탄피/먼지를 줄이고 탄도·작은 명중 효과를 유지하며, 카메라 시야각 변화/기울임을 없앤다. 모바일 기본값은 안정, 화면 흔들림 미저장 기본값도 끄기. PC는 기본 효과를 유지한다. 설정은 브라우저에 저장하고 맵 변경 때 다시 적용한다. 실제 사격 방향·피해/온라인 판정은 변경하지 않는다. 섬광탄의 게임 효과는 유지한다.

이 문제 경로를 수정했다는 사실과 사진 속 아이폰 제보의 원인이 확정됐다는 주장은 다르다. 실제 iPhone/Safari 사격 재확인은 남으며, Cloud Chromium의 모바일 화면은 실제 iPhone 검증이 아니다. 현재 런타임에는 WebKit 브라우저가 설치되어 있지 않다.
