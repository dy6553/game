# 서버 성장·폐공장·용접 로봇

2026-11-08 사용자 승인. 경험치와 레벨·해금·강화는 로그인 계정의 Neon DB에 저장한다. 비로그인 기본 게임은 유지한다. 기존 브라우저 개인 전적은 별도이며 과거 경기를 경험치로 소급하지 않는다.

## 확정 규칙

- 완료한 봇전/온라인 승리100XP, 패배50XP. 처치당10XP, 처치 보너스 최대100XP.
- 생존은 완료한 웨이브당20XP 추가. 패배한 현재 웨이브는 제외한다.
- 0XP Lv1, 이후200XP마다1레벨. 연습·중도 종료는 제외한다.
- Lv2/4/6에 강화1/2/3단계가 자동 적용된다. 단계마다 기본 피해+5%, 기본 재장전 시간−5%. 봇전만 적용하며 연습/온라인은 기본 성능이다. 봇 성능은 바꾸지 않는다.
- Lv3 폐공장 맵·용접 로봇 해금. 캐릭터는 외형만 다르며 용접 로봇은 기본 로봇의 판정·시점 높이·능력을 사용한다.
- 사용자 추가 확정: 폐공장도 온라인에서 플레이한다. 방 생성자의 맵을 공유하고 같은 맵끼리 자동 매칭한다. 초대 입장도 실제 방의 Lv3 조건을 서버에서 검사한다.

## 저장과 권한

기존 Neon/Worker 무료 구성에 추가한다. 새 서비스나 결제는 없다. `002-growth.sql`은 기존 전적을 보존하는 추가 마이그레이션이며 Worker가 계정/성장/공식 기록 첫 접근 시 트랜잭션으로 준비한다. 트랜잭션 advisory lock으로 여러 isolate의 최초 준비를 직렬화하고 실패 시 다음 요청이 재시도한다. 초기화 SQL은 `growth-schema.js`와 자동 비교한다.

성장 테이블/경기 영수증은 프로필 FK로 연결하며 계정 삭제 시 함께 삭제한다. RLS와 PUBLIC 권한 회수, Worker의 검증된 JWT subject로 본인만 조회/기록한다. 공개 전적에는 경험치·내부계정ID를 넣지 않는다.

온라인은 서버가 확정한 결과를 기존 공식 결과 outbox로 저장하면서 같은 영수증 트랜잭션에서 XP를 한 번만 더한다. 도입 이전에 끝난 지연 결과는 epoch로 제외한다. 클라이언트는 온라인 XP를 지급할 수 없다.

봇은 기존 클라이언트 시뮬레이션을 유지한다. 로그인한 경기 시작 시 서버 발급 영수증을 받고, 완료 후 서버가 모드/난이도/승패/처치·사망·웨이브 범위를 검증해 XP를 계산한다. 본인 경기만 정산하며 동일 ID 정산은 한 번만 적용한다. 이는 서버가 전투 전체를 재현하는 부정행위 방지 시스템이 아니며 공식 온라인 전적에 합산하지 않는다.

실패한 완료 요청은 계정별 영수증·결과만 브라우저 대기열에 남겨 새로 연결/홈 복귀/로그인/수동 재시도 시 전달한다. 토큰·비밀번호는 저장하지 않는다. 성공 응답 전에는 ‘저장 완료’로 표시하지 않는다. 로그인한 다른 기기는 서버의 총XP로 레벨/해금/강화를 복원한다. 경기 시작 전에 서버 연결이 실패하면 성장 연결 실패를 표시하고 게임은 계속 진행한다.

## 맵 구현

항구와 폐공장은 독립된 지형/문/계단/충돌/사격/길찾기 캐시를 사용한다. 폐공장은 다층 공장4개·창고4개·산업 엄폐물8개와 굴뚝/지붕 보강/안전선을 사용한다. 서버는 맵ID를 경기 체크포인트에 저장하고 재접속 시 복원한다. 클라이언트도 서버 맵에 맞춰 화면과 이동 예측을 선택한다. 총 보급 위치와 지상/야외 생성 규칙은 유지한다. 외부 유료 에셋 없이 직접 만든 기하 모델이다.
