# 설산·달기지 코드 맵 — 2026-11-17

설산의 이후 이글루·폭설 개편은 [최신 규칙](igloo-blizzard.md)을 따른다. 아래는 첫 코드 맵 제작 시점의 기록이다.

사용자가 현재 배포된 설산·달기지를 Blender 모델 없이 코드로 다시 만들고 저·중·고 6개 외형으로 나눌 것을 요청했다. 주요 동선·출입구·엄폐물을 유지하고 같은 맵의 그래픽 등급끼리 함께 경기하도록 한다. 기존 항구·공장 맵은 이번 재제작 대상이 아니다.

## 구성

`src/procedural-expansion.ts`에서 맵 2종 × 프로필 3종을 직접 생성한다. `scene.ts`의 설산·달기지 기본 경로는 GLB를 요청하지 않는다. 명시적인 `expansionArtSource`는 기존 모델 검증·호환을 위해 유지하며 옛 파일을 삭제하지 않는다.

- 설산: 눈 덮인 외곽 능선, 청록색 띠의 3개 연구동, 중앙 관측 돔, 따뜻한 입구 표시, 접근로와 작은 발자국.
- 달기지: 크레이터 색조의 평탄한 지면, 중앙 H 착륙장, 밝은 거주동의 돔, 짙은 운영동의 통신 접시, 금색 안내 띠, 지구와 별.
- 같은 팔레트와 랜드마크는 저·중·고 모두 유지한다. 중·고에서 표면 해상도·돔/지형 곡면·벽 이음매·지붕 설비의 세부 표현을 늘린다.
- 저사양은 실시간 그림자와 야외 눈 입자를 생략한다. 눈 설정 자체는 보존해 중·고로 돌아오면 사용자 선택을 따른다.
- 공간별 불투명 정적 배치 14개(설산)/11개(달기지), 공유 재질 4개, 자체 생성 질감 2개를 사용한다. 투명 유리·반사·새 동적 광원·실시간 후처리를 추가하지 않는다.

## 구조·판정

설산 160×120m, 달 100×80m의 기존 공유 좌표/건물/솔리드 목록을 재사용한다. 시각 모델의 벽·엄폐물은 공유 상자를 기반으로 만든다. 새로운 길막 장식을 플레이 구간에 추가하지 않고, 추가 장식은 벽 표면·지붕·평면 표시 또는 경기장 바깥 능선에 제한한다. 고저 지형은 경기장 바깥의 배경이며 플레이 바닥은 기존처럼 평탄하다. 저중력·파괴·새 계단 같은 게임 규칙을 새로 확정하지 않는다.

보이지 않는 기존 판정 메시를 유지해 이동·사격·봇·서버 권한과 맵/모드/계정 해금을 보존한다. 품질 전환 때 이전 루트·버퍼·재질·질감을 해제한다.

설산/달 가장자리 핑을 기존 항구 범위로 거부하던 검증은 실제 맵 경계를 사용하도록 수정했다. 기본 `parseCommand`의 항구 범위 호환은 유지한다. 기존 병합본에서 부활 때 낙하 속도를 삭제하던 회귀도 기존 검사에 맞춰 0으로 초기화한다.

## 달기지 구조 개편

중앙 착륙장, 남쪽 크레이터 둘레 엄폐로, 두 건물을 잇는 실내 통로를 구성했다. 양쪽 통로 입구에는 접근하면 열리는 자동문을 설치했다. 거주동과 운영·통신동에는 각각 2층 계단과 착륙장 쪽 관측창이 있다. 달기지 실외 점프 높이는 실내보다 약 30% 높다. 그래픽 등급과 관계없이 이동·사격은 같은 지형을 사용하며, 온라인은 `moon-v2` 지형과 문 상태를 서버에서 적용한다.

회귀 검사에서 첫 프레임에 닫힌 자동문이 광선에 잡히지 않는 문제를 확인했다. 문 생성 시 사격 판정을 초기화하고 월드 행렬을 고정한 뒤 사격 차단, 통로 횡단, 양쪽 2층 진입과 실내외 점프 높이 검사를 통과했다.

### 달기지 점프와 낙하

달기지 실외 중력은 1.62m/s², 건물과 연결 통로의 인공중력은 9.81m/s²로 조정했다. 점프 시작 속도도 함께 조정해 같은 높이의 바닥으로 돌아오는 점프는 실외 약 2.53초·최고 1.3m, 실내 약 0.90초·최고 1m가 된다. 2층 가장자리에서 바닥 높이 아래로 내려갈 때도 하강 속도를 이어받는다. 새 온라인 달기지 리비전은 `moon-v3`다.

기존 구현에서 첫 상승 높이와 낙하 변위가 새 규칙을 만족하지 않는 것을 먼저 확인했다. 구현 후 오프라인 장면과 온라인 공용 이동에서 실내외 상승 곡선·착지 시간·기존 점프 높이를 확인했고, 2층 이탈 시 하강 속도 유지와 착지 검사를 통과했다.

### 달기지 외곽 확장과 산소·일식

달기지 `moon-v4`는 140×112m이며, 외곽 네 곳에 O2 표식이 있는 산소 쉼터를 배치했다. 기본 마스크는 실외에서 초당 2%를 소모한다. 건물·연결 통로·쉼터는 초당 12%를 충전하고, 0%인 동안에는 초당 체력 8을 잃는다. 경기 시작·부활 때 100%로 채운다. 일식은 경기 85초에 시작해 25초간 지속되고, 180초 주기로 반복된다. 10초 전 예고하고 실외 조명을 점차 낮춘다. 온라인은 서버에 산소와 경기 시간을 저장한다.

기존 달기지에서 맵 폭과 실외 산소 소모 검사가 실패하는 것을 확인한 뒤 구현했다. 충전·고갈 피해, 네 입구의 이동·실내외 판정, 일식 예고와 서버 시각 연동을 검증한다.

### 랜덤 일식과 산소 마스크 착용

달기지 `moon-v5`의 일식까지 맑은 구간은 55~120초, 일식은 15~35초다. 경기 시드와 경과 시간으로 일정을 정하며 10초 전 예고를 유지한다. 고화질에서만 밀집된 은하수 별 배치와 지구 구름·명암을 그린다.

시작과 부활 시 산소는 100%이며 마스크는 미장착이다. 경량 20초, 표준 35초, 장시간 50초를 체력 HUD의 버튼으로 착용한다. 종류마다 부활 전까지 1회 사용할 수 있다. 작동 중 실외 산소 소모는 정지하고 타이머는 실내에서도 흐른다. 실내는 산소 게이지를 보충한다. 마스크 소비·만료·일식 시드는 온라인 서버 상태로 처리한다.

### 벽면 마스크 보급대

`moon-v6`부터 두 주 건물과 네 산소 쉼터의 1층 안쪽 벽에 마스크 보급대가 있다. 보급대 가까이에서 세 종류 중 하나를 줍고, 소지한 마스크는 별도로 착용한다. 소지 한도는 한 개다. 이미 착용한 마스크의 시간이 다 되면 언제든 빈 마스크를 버릴 수 있고, 이후 보급대에서 다시 가져올 수 있다. 서버는 동일한 방 안에서 거리와 층을 확인한다.

`moon-v7`에서는 경기 시드가 보급대 자리를 결정한다. 주 건물에는 각각 3개씩, 외곽 산소 쉼터에는 각각 2개씩 총 14개를 설치한다. 후보는 1층 내벽에 한정하며, 기존 6개 고정 배치에서 실패했던 개수 검사가 14개와 시드별 위치 차이를 확인한다. 같은 경기의 표시와 획득 판정은 동일한 배치 함수를 사용한다.

### 달기지 산소 HUD, 외부 출입문, 압력 모듈

`moon-v8`에서는 산소 숫자와 잔량 바를 체력 HUD에 따로 표시한다. 주 모듈의 양쪽 입구와 네 쉼터에 자동 출입문을 추가해 닫히면 충돌과 사격을 차단한다. 모듈 외벽에는 밀폐 패널과 지붕 덮개를, 내부에는 천장 조명을 그린다.

달 표면의 게임 중력은 1.62m/s²이며 우주복 점프의 초기 수직 속도는 2.6m/s로 튜닝했다. 같은 높이에 착지할 때 약 2.09m까지 오르고 약 3.21초 동안 공중에 머문다. 실내 인공중력은 9.81m/s²이며 천장과 2층 바닥에 머리가 닿으면 상승을 멈춘다. 외부 문 차폐와 실외 점프 수치 검사가 이전 코드에서 실패하는 것을 확인하고 수정했다.

### 달기지 중앙 통과로와 착지

`moon-v9`는 중앙 연결 통로 양쪽 사이에 6.4m 폭의 실외 통과로를 둔다. 연결 통로에는 중앙을 향한 자동문을 추가한다. 실외 중력 1.62m/s²에서 점프 초기 속도를 1.7m/s로 조정해 같은 높이까지 약 2.10초 만에 착지하며, 최고 높이는 약 0.89m다. 산소 고갈 시 피격 테두리 효과를 줄이고 일식 중 실외 조명의 최소 밝기를 높였다. 기존 배치에서는 중앙 벽 통과와 새 점프 궤적 검사가 실패하는 것을 확인한 뒤 수정했다.
