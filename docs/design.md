## 2. 시점·입력·시제품 값

휴대폰 가로 화면에서 왼쪽 스틱 이동, 빈 화면 드래그 시점, 단일 정면 발사, 점프·재장전 버튼. PC WASD/마우스/왼쪽 클릭/R. PC 점프는 실행 중Space/J를 선택한다. 프로젝트 기본 점프·대시 키는 답변 대기, 대시는 미구현이다.

임시 맵 경계 x±44/z±34, 이동속도7, 충돌 반경0.55, FOV1.25라디안, 눈높이1.9~1.95. 점프 중력18/출발 수직속도6은 조작 시제품 값이며 장애물 넘기·상자 위 착지는 없다. 최종 온라인 경기 수치로 확정하지 않는다.

선택·비교·세로 안내·앱 비표시 중에는 연습 시계와 점프를 멈춘다. 복귀의 긴 프레임을 재장전 시간에 합산하지 않는다. 캐릭터 교체는 탄약·표적을 초기화하지 않는다.

## 3. 사격 판정과 연출

승인된12발/1.5초 재장전·표적100체력/피해25를 적용한다. 카메라 중앙 광선의 가장 가까운 실제 지형·표적 교차로 명중을 즉시 판정한다. 시각적 궤적은 이 결과의 끝점을 사용하며 피해 판정을 지연시키거나 새 탄도 규칙을 추가하지 않는다. 총구가 가까운 벽 뒤에 들어가면 효과 시작점도 벽 앞쪽으로 제한한다.

총구 화염은 짧게, 이동 궤적은 가늘고 짧게 표시한다. 표적은 청록 피격 불꽃, 벽은 따뜻한 불꽃·먼지·탄착 흔적을 표시한다. 탄피는 짧게 튀고 제거한다. 실제 명중만 HUD에 표시하고 빈 탄창·재장전 중에는 가짜 발사 효과도 만들지 않는다. 재사용 풀 상한: 궤적8, 불꽃48, 탄피12, 탄착24, 먼지6. 효과는 모두 탄환 비대상이다. 리셋/메뉴 전환은 효과를 정리한다.

참고한 원칙·출처는 `docs/shooting-reference.md`를 따른다. 타 게임 파일·모델·음원·셰이더를 가져오지 않았다.

## 4. 그래픽과 단일HTML

밤의 따뜻한 석재·창빛과 푸른 그림자는 확정된 거리 시안을 기준으로 개선 중이다.512px 표면, 이방성 필터링, 해상도 설정을 제공한다. 도움말의 “높음”은 기기 픽셀 비율을 최대2까지, 그림자2048·필터8로 설정한다. “균형”은 최대1.25·그림자1024·필터2다. 이는 렌더 해상도 상향이며 AI초해상도 모델을 사용하지 않는다. 기기별 FPS·발열은 미검증이다.

단일HTML은 ES2019 문법으로 코드·스타일을 내장하고 시작 진단을 먼저 실행한다. 대형 시안 PNG는 번들에 넣지 않고 비교 시 파일 선택기로 읽는다.2,000,000바이트 미만 구조 검사를 유지한다. 원본 사진과 실제 렌더의 일치율은 자동 검사로 판정하지 않는다.

## 5. 미구현 서버 설계 경계

온라인 채택 시 입력·이동·발사·피해·승패는 서버가 검증하고 경기ID로 결과를 한 번만 저장한다. 인증·전적·로비·매칭·재접속·무료 호스팅 선택은 미정이다. 현재 로컬 연습을 온라인 서버 구현으로 취급하지 않는다. 로컬 개발 기술 외의 GitHub/Colyseus/Render/Vercel/Neon 등은 여전히 후보이며 도입 전 공식 무료 조건과 사용자 선택이 필요하다.

## 봇 1대1 구현

`duel.ts`는 2단위 격자 경로를 탐색하고 공통 반경·충돌로 각 경로 구간을 검사한다. 0.75초 간격으로 길을 다시 찾으며 실제 장면 광선으로 시야를 확인한다. 시야를 잃으면 조준 시간이 초기화된다. 상대는 고양이형 로봇과 붉은 머리 위 체력 표시다. 적 사격에도 별도 고정 크기 효과 풀을 사용한다. 로봇 메시의 실제 광선 교차로 플레이어의 명중을 판정한다.

메뉴·비교·앱 숨김·세로 회전 중 경기 진행을 멈춘다. 사망 및 경기 종료 중 이동·발사·점프·재장전을 막는다. 플레이어 부활 때 위치·체력·탄창·점프를 복구한다. 대전의 출발점 버튼은 비활성화한다. 점수는 로컬 메모리뿐이며 공식 전적이나 온라인 검증이 아니다.

## 회피·체력·피격 개선 — 최신 기준

사용자가 봇 공격 회피와 전투 피드백 개선을 요청하여 확장했다. 기존 즉시 확정 피해를 제거했다. 봇은 시야1초 조준 후 위치를 고정하고0.4초 경고 뒤 발사한다. 고정 위치에서0.65보다 멀리 이동하면 피해를 받지 않는다. 매 발사 후 조준을 다시 시작하며0.8초 발사 대기 조건도 유지한다. 경고 중 엄폐·사망하면 고정을 취소한다. 발사 광선이 지형에 막히면 피해 없이 실제 벽에서 효과를 멈춘다. 피해25·체력100·3초 부활·10킬 목표는 유지한다.

## 모바일 UI 겹침 수정

사용자 가로 스크린샷 기준: 체력판이 왼쪽 스틱을 덮고 탄약판이 오른쪽 점프/발사 영역에 들어옴. 모바일·짧은 화면은 제목/지역 표시를 숨기고 메뉴 버튼으로 툴바를 접음. 체력/점수는 왼쪽 위, 탄약은 오른쪽 위, 이동은 왼쪽 아래, 발사/재장전/점프는 오른쪽 아래에 독립 배치. 도움말은 높이 제한과 스크롤 제공. 메뉴/도움말 중 전투 정지, 화면 크기 변경 시 메뉴 닫기. 실제 기기 시각 검증은 사용자 확인 필요. 타입/빌드와 단일HTML 시작 검사로 구조 확인.

## 무기4종 확장 — 최신 상태

사용자가 승인한 기관총(피해10/30발/초당8발/재장전2초), 산탄총(6개 탄알 각피해10/6발/간격0.9초/재장전2.5초), 저격총(피해100/5발/간격1.5초/재장전2.5초/확대)을 추가했다. 권총은 기존25피해/12발/재장전1.5초를 유지한다. 예비 탄약은 기존 연습의 무제한 방식이다. 봇은 기존 권총을 유지한다.

메뉴의 시작 무기 선택을 변경하면 점수·표적·봇·탄약·위치를 초기화하여 새 경기/연습을 시작한다. 현재 여러 무기를 동시에 소지하거나 경기 중 교체하는 기능은 아니다. 기관총은 발사 버튼을 누르고 있거나 PC 마우스 고정 상태에서 왼쪽 버튼을 누르면 연사한다. 손가락 취소·포커스 이탈·메뉴 진입은 연사를 멈춘다. 산탄은 여섯 개의 분리 광선으로 벽/표적/봇의 실제 명중과 피해를 계산한다. 저격총 확대는 모바일 버튼/PC Q키로 전환한다.

무기별 탄창·재장전·발사 간격·총 외형·HUD·피해 표시를 반영했다. 자동 검사30개 통과 및 타입/프로덕션/단일HTML검사를 수행했다. 실제 휴대폰 연사/조준 및 GPU화면은 별도 확인 필요. 다른 AI모드·대시·획득/최대3개 소지·온라인·계정·전적은 미완료다.

## 사운드 추가
무기·명중·피격·이동·경기·환경음과 음량 설정을 추가했다. 출처와 검증 한계는 docs/audio.md 참조.

## 배포 방식 변경
사용자 요청에 따라 단일HTML 배포/빌드/2MB검사를 종료했다. 웹 전용으로 JS/CSS/음원/향후 에셋을 분리 관리한다. 실제 기기 성능과 웹 호스팅 한도는 유지되며 크기를 무제한으로 키우지 않는다.

## 확장 맵·실내·그래픽 — 최신 기준

이동 가능 경계 x±64,z[-60,34], 기존 x±44,z±34 대비 경계 면적 약2배. 북쪽 항구는 유지하고 남쪽 상점 거리와 동서 외곽 골목을 확장했다. 건물은8동에서16동, 이 중6동은 열린3.2너비 입구로 들어갈 수 있는1층이다. 별도 문 버튼이나 로딩 전환 없이 출입한다. 위층/계단/옥상 출입은 구현하지 않았다.

실내 바닥·천장·따뜻한 조명·카운터·테이블·진열대·책과 소품을 추가했다. 닫힌 건물은 전체 장애물, 실내는 실제 분리 벽과 가구를 공통 SOLIDS로 사용한다. 문 개구부에는 이동/광선 장애물이 없고, 옆 벽은 사격을 막는다. 봇도 같은 충돌 데이터로 경로를 찾는다. 실내 조명은 현재 들어간 방만 켜 성능을 제한한다. 경계 밖 바다로 걷는 것은 막는다.

표면을512에서1024px로 올리고 나무 바닥 재질을 추가했다. 새 거리에도 랜턴·바닥 빛·반사 표현을 확장하고 항구 난간을 연장했다. 이미지 기반 실사/실시간 반사나 시안100%근접을 주장하지 않는다.

검증: 타입/프로덕션 빌드 및 자동검사34개. 6곳 실내 출입·벽 충돌·봇 경로·실제 장면 개구부 광선 통과/벽 차폐·실내 조명 전환·확장 지역 이동과 기존 전투 회귀를 확인했다. 실제GPU화면·모바일 프레임/발열·실내미술체감은 미검증. 웹 전용으로 전달한다.

## 달리기 추가 — 최신 결정

사용자는 대시보다 달리기를 먼저 추가하도록 변경했다. 승인 규칙: 기본 이동1.5배, 스태미나 없음, 앞으로 이동할 때만 적용, 발사/재장전/확대 중 걷기 전환. PC는 ShiftLeft/ShiftRight를 누르는 동안, 모바일은 이동 스틱 위의 달리기 토글 버튼. 작은 높이 화면에서는 버튼을 스틱 옆으로 옮긴다.

방향과 대각선 정규화 및 공통 벽·가구 충돌을 유지한다. 메뉴·도움말 전투 정지 및 입력 reset/blur/visibility/회전은 달리기 입력을 해제한다. 대시/무적은 구현하지 않았다.

검증: 타입·웹 프로덕션 빌드 및 자동검사36개 통과. 달리기 조건·벽 관통 방지·Shift 누름/뗌·모바일 토글/reset을 검사했다. 실제 휴대폰 터치/버튼 배치·프레임·달리기 체감은 미검증.

## 시각 처리·렌더링 최적화 — 최신 우선순위

사용자 요청으로 무기 획득/3개소지/교체 작업을 보류했다. 준비한 코드는 docs/drafts에 보관하고 실행 앱에 연결하지 않는다. 사용자 추가 요구인 사망 시 기본 무기 부활은 재개 시 반영할 사항으로 기록한다. 이번 변경은 그래픽/시각 처리에 한정한다.

기본 화질을 자동으로 변경했다. 휴대폰은 초기 픽셀 비율 상한1.5, PC1.75(기기의DPR이 더낮으면 그값)를 사용한다. 2초간 지속 프레임 추정이28미만이면 비율을0.15 낮추고 최저0.75를 적용한다. 50초과 구간이3회 연속이면0.05씩 복구한다. 메뉴/비활성 구간은 판정하지 않는다. 높음 수동모드(최대2), 균형 수동모드(최대1)는 자동 해상도 변경을 하지 않는다. 특정FPS를 보장하거나 실측 향상을 주장하지 않는다.

고정 건물·거리·반사 메시의 월드 행렬을 동결하고 동적 캐릭터/표적/카메라는 제외했다. 그림자 범위를 플레이어 주변64로 집중하고 텍셀 크기에 위치를 맞춰 이동 시 떨림을 줄이는 구조를 적용했다. 그림자맵은 값이 바뀔 때만 재생성한다. 균형 화질에서도 표면필터를4로 유지한다.

젖은 바닥의 움직이던UV를 고정해 반사가 미끄러지지 않게 했고, 노면·수면 반사의 강도를 낮췄다. 추가 가로등 글로는 높은 품질에서38이내 거리만0.2초 간격으로 활성화한다. 이미 합쳐지며 폐기된 메시 참조를 관리 목록에서 제외했다.

검증: 타입/웹 빌드 및 자동검사39개. 자동해상도의 하한/복구지연/일시정지, 고정 메시의 동결과 동적 객체 유지, 기존 실내/전투/달리기를 확인한다. 실제 GPU화면·휴대폰 FPS/발열·화질 향상은 아직 미측정이다.
