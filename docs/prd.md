# 제품 요구사항 문서 (PRD)

## 봇 3명 개인전 — 2026-11-06 사용자 확정

나와 봇3명, 총4명이 각자10킬을 경쟁하는 모드를 구현했다. 사용자는 세부 선택에서 ‘봇은 플레이어만 공격’을 선택했다. 따라서 봇끼리 싸우지 않는다. 봇3명은 선택한 동일 난이도/권총, 체력100·3초 부활을 사용하며 부활은 살아 있는 캐릭터들과 가장 먼 충돌 없는 후보 지점에서 한다. 무적 시간은 추가하지 않는다. 플레이어는 기존 무기 상자/3개소지/시작 총 부활을 유지한다. TDD 및 자동80개·PC/모바일 DOM 검증은 [봇3명 개인전](bot-group.md)을 따른다. 실제 기기 프레임·조작·난이도 체감은 별도 확인한다.


## 봇 난이도 확장 — 2026-11-06 사용자 승인

봇1대1의 쉬움·보통·어려움을 구현했다. 승인 수치: 쉬움 기존 조준1초/경고0.4초/이동3 유지, 보통0.7초/0.35초/이동4, 어려움0.45초/0.3초/이동5. 보통·어려움은 조준 중 좌우 이동하고 발사 경고 중 멈춘다. 모든 난이도는 체력100·피해25·3초 부활·10킬, 권총 탄약/재장전과 최소 발사 간격0.8초를 유지한다. 시작 화면/메뉴에서 선택하고 변경 시 새 경기, 재시작 시 선택 유지. TDD Red→Green 및 자동74개 검증은 [봇 난이도](bot-difficulty.md)를 따른다. 개인전·웨이브 생존·자동 난이도·성장은 후속이다.


## 점프·시점 수정 및 무기 획득 재개 — 2026-11-06

사용자가 점프 떨림·드래그 후 기울어짐 수정과 무기 획득을 요청했고 추천 세부 규칙을 승인했다. 이전 무기 획득 보류를 해제한다. 보급 상자 근처2.5m에서 PC E/획득 버튼, 최대3개·1~3/슬롯 교체, 가득 차면 버릴 슬롯 선택, 중복 획득 불가, 상자20초 후 재생성(경기 진행 시간), 버린 총 제거, 사망 시 선택한 시작 총만 복구한다. 온라인은 거리·소지·재생성·교체·부활을 서버가 확정한다. 자동70개와 빌드/DOM 검사, TDD 실패→통과 기록은 [점프·시점·보급 기록](jump-view-pickups.md)을 따른다. 실제 GPU/휴대폰 체감 확인은 별도다.

Vercel production VITE_ONLINE_URL 설정 및 재배포 완료. 공개 서버에 실제 WebSocket 2개를 연결해 방 생성·입장·정원 제한·잘못된 Origin 차단·서버 판정 처치·재접속·나가기·자동 매칭을 통과했다. 실제 기기 간 플레이/GPU/네트워크 체감 검증은 남는다. 루트 wrangler.jsonc로 Cloudflare가 정적 웹 대신 서버 코드를 배포하도록 수정했다.

## 최신 승인·구현 — 2026-11-06

사용자는 웹 검토 추천 전체 적용을 요청했다. 시작 화면에서 캐릭터·게임 모드·시작 무기를 선택하고, PC 마우스 고정은 별도 버튼으로 수행한다. 도움말 닫기/Esc·일시정지/계속하기·정지 중 입력 차단·모바일 조준 감도 저장·최근 프레임 통계를 제공한다. PC 기본 점프는 Space이며 J 선택 가능하다. 무기 획득/3개 소지/교체는 이번 사용자 승인으로 재개했고 상단 최신 규칙을 따른다. 아래 과거 기록과 충돌하면 이 절과 [수정 기록](review-improvements.md)의 최신 구현을 우선한다.

상태: 요구사항 확정 진행 중 / 현재 구현: 홈·표적 연습·쉬운 봇1대1·공개 온라인1대1

## 1. 목표와 범위

애니풍 항구 도시의 건물·골목·광장을 다니며 두 로봇 중 하나로 싸우는3D 1인칭 아레나 슈팅을 만든다. AI 및 온라인 대전을 제공하는 것이 최종 범위다. 현재 오프라인 표적 연습과 쉬운 봇 1대1을 구현했으며 문서·시안·시제품을 전체 게임 완료로 간주하지 않는다. 기존 사이버 미래 도시의 방향은 최신 항구 거리 시안을 우선해 구체화한다.

## 3. 승인된 권총 연습 규칙

## 6. 수용 조건과 제한

점수·승패·공식 전적은 서버 검증을 거친다. 클라이언트의 결과를 그대로 저장하지 않는다. 서비스 도입 직전에 무료 한도·카드 요구·절전·초과 시 동작을 공식 자료로 확인한다. 다른 실제 기기·네트워크의 온라인 경기, 실제 모바일 회전·앱 전환·동시 터치, 비밀키 노출과 타인 기록 수정·결과 중복 방지를 검증해야 전체 완료로 판정한다.

팀전·온라인3인 이상·공개 랭킹·채팅/음성·상점·결제·성장 보상/해금·추가 맵·대화형AI는 별도 승인 범위다. 현재 제목 “항구의 밤”은 작업용이며 정식 이름 확정이 아니다.

이전 대화·변경 기록은 `docs/history/prd.before-fx-sync.md`와 `HANDOFF.md`에 보존한다.

## 7. 승인 및 구현 — 봇 1대1

사용자가 제안대로 진행하도록 승인: 양쪽 체력100·권총 피해25·자동 회복 없음, 봇은 연속 시야1초 조준 후0.8초 간격 발사, 사망3초 후 체력·탄창 복구, 먼저10킬 승리. 기존 권총12발/재장전1.5초/예비무한 사용. 봇도 탄약을 소비하고 재장전한다. 경기 종료 후 다시 시작으로 점수·체력·탄약·위치를 초기화한다. 연습/대전 전환 역시 새로 시작한다.
