# 게임 전체 화면

경기 화면의 메뉴 아래 전체 화면 버튼은 페이지 전체에 Fullscreen API를 요청하여 게임과 터치 조작을 함께 표시한다. 다시 누르거나 브라우저에서 해제하면 버튼 상태가 갱신된다. 지원하지 않거나 요청에 실패하면 게임을 유지하고 안내한다. 주소표시줄 및 시스템 표시 여부는 브라우저와 기기에 따라 다르다.

TDD: 구현 전 테스트에서 버튼 상태 미설정과 지원 불가 안내 누락으로 실패함을 확인했다. 구현 후 전체 화면 진입·해제, 외부 해제, 미지원·거부 테스트 2개와 기존 터치·시점 테스트 16개, 운영 빌드가 통과했다. 삼성 인터넷 실기기와 녹화 동작은 별도 확인이 필요하다.
