# 로비 무기·대기 동작·회전·출격 효과 — 2026-11-07

사용자가 로비 캐릭터의 선택 총 들기, 자연스러운 대기 동작, 드래그 회전, 선택/출격 효과음과 전환 연출 추천을 승인했다. 전투 규칙·피해·실제 인벤토리와 온라인 서버는 변경하지 않는다.

## 구현

- `src/lobby-weapons.ts`: 권총/기관총/산탄총/저격총의 로비용3D 모델을 한 번 생성한다. 무기별 부품을 재질별로 합쳐 총12개 메시로 유지하고 선택 모델만 표시한다. 추가 조명/이미지/네트워크 요청 없이 기존 금속 재질을 재사용한다. 사격/충돌 비대상이다.
- `src/characters.ts`: 기존 메시 위치를 보존하는 어깨/팔꿈치 피벗을 추가한다. 로비에서 오른팔로 총을 들고 긴 총은 왼팔로 받치며, 손바닥에 무기 마운트를 연결한다. 캐릭터 교체 전 마운트를 분리한 뒤 새 손에 연결한다. 작은 호흡/몸 흔들림을 적용하고 로비 밖에서는 원래 자세로 되돌린다.
- `scene.ts`: 시각 전용 무기 선택과 로비 회전을 실제 무기/탄약과 분리한다. 수동 회전은 한 바퀴로 정규화하고 게임 중에는 무시한다. 로비 반복 진입/무기 선택으로 메시/재질을 재생성하지 않는다. 게임 시작 시 총 모델과 자세를 숨기고 기존1인칭 카메라/무기를 사용한다.
- `src/lobby-polish.ts`: 중앙만 드래그 영역으로 사용한다. Pointer Capture로 화면 밖 이동을 처리하고 두 번째 손가락·취소·포커스 상실·선택창 진입을 처리한다. 좌우 방향키/초기화 버튼/Home 키도 지원한다. 실제 게임의 시점/이동 입력에 전달하지 않는다.
- 선택 시 짧은 UI 효과음/장비 표시 페이드, 출격 시280ms 전환과 전용 효과음을 적용한다. 출격이 끝날 때까지 내 게임 입력을 잠깐 차단한다. 온라인은 서버에 새 규칙을 추가하거나 상대 경기를 멈추지 않는다.
- `audio.ts`: 게임 정지와 분리된 인터페이스 채널을 추가했다. 기존 전체/효과음 음량·음소거를 사용하며 창 비활성화 시 중지한다. 동시에 최대4개 UI 소리, 기존 게임 효과는24개 제한을 유지한다. 새 음원 없이 합성 UI/출격 소리를 사용한다.
- 시스템 ‘동작 줄이기’는 자동 대기 동작·장비 페이드·출격 애니메이션을 끈다. 명시적인 드래그/키보드 회전은 사용할 수 있다. 숨김/비활성 창이나 선택창 중에는 대기 동작을 멈춘다.
