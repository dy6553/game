# 게임 안의 선택창과 로비 UI — 2026-11-07

사용자가 휴대폰의 기본 select 선택창이 표시된 스크린샷을 보내고 게임 안에서 고르는 창과 게임 로비다운 UI를 요청했다. 기존 게임 규칙이나 선택지는 바꾸지 않고 선택 화면과 표현을 수정했다.

## 구현

`src/game-choices.ts`가 기존 select의 상태를 게임 안의 버튼과 공통 카드 대화상자로 표시한다. 실제 select는 hidden/aria-hidden/tabIndex=-1로 숨겨 모바일 OS 선택창이 열리지 않게 한다. 원래 필드의 값과 change 이벤트를 그대로 사용하므로 모드·난이도·시작 무기·온라인·그래픽 등 기존 로직을 유지한다. 홈뿐 아니라 게임 중 준비/설정 및 온라인 로비에도 적용한다.

- 현재 설정은 ‘변경’ 버튼으로 표시한다. 누르면 설명·선택 표시가 있는 게임 UI 카드를 연다.
- 선택한 카드를 누르면 적용하고 닫는다. 닫기·바깥 영역·ESC는 취소하며 값은 유지한다.
- 선택창에 포커스를 두고 Tab/방향키/Home/End를 지원한다. 닫으면 원래 버튼으로 포커스를 돌린다.
- 선택창 뒤의 화면은 inert로 만들고 조작/게임 진행을 정지한다. 온라인 서버 경기는 기존대로 계속되며 내 입력만 차단한다.
- 숨김/비활성 옵션은 카드로 제공하지 않는다. 생존 전용 자동 난이도와 온라인 중 비활성 설정 상태를 유지한다.
- 프로그램에서 변경한 원래 필드 값과 disabled 상태를 표시 버튼에도 반영한다. 화면 전환/온라인 입장/결과 창이 열릴 때는 이전 선택창을 정리한다.

로비는 출격 로비/장비 메뉴, 장비 준비 상태 패널, 임무 보드 스타일의 프레임·선택 강조·출격 버튼으로 다듬었다. 직접 만든 기존 SVG 미리보기와 무료 리소스 원칙을 유지한다. 새 패키지/외부 이미지/서버/수집 항목을 추가하지 않는다. 가로 모바일의 시작 버튼 고정도 유지한다.
