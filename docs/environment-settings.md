# 환경설정과 목표 프레임

2026-11-08 사용자 요청: 환경설정에서 그래픽/프레임을 조절하고 편의 기능을 더 추가한다.30/60/90/120/제한없음과 기본60 추천안을 제시했으며, 기본60으로 구현한다. 프레임 설정은 렌더링 상한으로 실제 FPS를 보장하지 않는다.

## 화면과 설정

홈 상단 ‘환경설정’, 전투 ‘메뉴→환경설정’, 온라인 대기방 ‘환경설정’에서 같은 화면을 연다. 그래픽·사운드·조작·화면4개 탭, 키보드 화살표/Tab/Esc와 초점 복귀, 작은 가로 화면의 내부 스크롤/고정 닫기·초기화 버튼을 지원한다. 기존 도움말의 설정 컨트롤을 옮겨 이벤트와ID를 재사용하고 게임 안내와 분리했다. 기존 게임 내 선택창을 그대로 사용하여 모바일 OS select창이 뜨지 않는다.

| 분류 | 제공 기능 |
| --- | --- |
| 그래픽 | 자동/높음/균형/낮음, 목표30/60/90/120/제한없음, 그림자 켜기/끄기, 안정/기본 사격 효과, 화면 흔들림 |
| 사운드 | 전체·효과음·환경음 음량과 수치, 음소거, 좌우 방향음 확인 |
| 조작 | 모바일 조준 감도, 별도PC 마우스 감도0.25~2배, PC 점프 Space/J |
| 화면 | 전투 글씨 기본/크게, 조작 버튼 투명도40~100%, 조준점 흰색/초록/노랑과 기본/크게 |

낮음은 렌더 픽셀 비율 상한0.75, 균형1, 높음2이며 기기DPR보다 올리지 않는다. 자동은 기존 지속 프레임 기반 해상도 조절을 유지한다. 그림자는 독립 설정이다. 조작 버튼 투명도는 표시만 변경하며 버튼 크기와 터치 영역을 바꾸지 않는다. 전투 글씨/조준점은 화면 표현만 변경하고 조준 방향·피해·사격 판정을 바꾸지 않는다. 실제 기기 발열/FPS 개선률을 주장하지 않는다.

## 시간과 온라인

`frame-limit.ts`는3D 렌더 호출만 제한한다. 기존 메인 갱신 루프, 오프라인 시뮬레이션 단계, 온라인20Hz 명령 전송과 서버 판정은 유지한다.90/120은 브라우저/화면이 제공하는 주사율까지 동작하며, 제한없음도 브라우저 프레임 루프를 따른다. 목표 변경/백그라운드 복귀 때 과거 프레임을 몰아서 그리지 않는다.

환경설정이 열려 가려진3D는 그리지 않고 조작 입력을 초기화·차단한다. 봇전은 멈추며 온라인은 자신의 조작만 멈추고 경기 수신/시간은 계속된다. 온라인 결과가 확정되면 설정을 닫고 결과를 보여준다. 메뉴/마우스 고정·선택창과 inert 상태를 복구하여 복귀 후 조작이 먹통이 되지 않도록 한다.

실시간 FPS 숫자 HUD는 다시 추가하지 않았다. 선택한 목표 FPS만 환경설정에 표시한다.

## 저장과 초기화

설정은 기기/브라우저별 `harbor-environment-v1`에 자동 저장한다. 기존 음량·모바일 감도·사격 효과·흔들림 키는 재사용해 이전 값을 보존한다. 맵 변경 후에도 그림자/품질과 사격 효과를 재적용한다. 저장 접근이 차단돼도 현재 접속의 조절은 동작하고 저장 불가를 안내한다. 손상/지원하지 않는 값은 기본값 또는 안전 범위로 정리한다.

‘기본값 복원’은 환경설정과 기존 소리/감도/화면 설정만 되돌린다. 계정/닉네임/성장/전적/진행 중 경기/저장 대기 결과를 삭제하지 않는다. 새 DB·서비스·패키지·계정 데이터 전송은 추가하지 않았다.
