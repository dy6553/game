# 이글루 탐사기지와 주기적 폭설 — 2026-11-17

사용자가 ① 이글루 탐사기지를 선택했고, 맑음/폭설의 주기 전환과 모든 그래픽 등급의 동일한 시야 제한·봇 탐지 제한을 승인했다. 설산만 개편하며 달기지·항구·공장의 건물과 기본 규칙은 유지한다.

## 건축과 판정

- 중앙 이글루: 36×30m의 타원형 발자국, 높이 11m의 눈 블록 곡면. 사각 건물의 지붕 교체가 아니라 벽·실내 천장·입구를 새로 구성했다.
- 양옆 연구동: 기존 중심 위치 ±33m와 긴 동선을 유지한 아치형 연구동. 중앙 연결 터널, 전후방 입구, 짧은 아치형 에어록을 연결했다.
- 기존 연구 콘솔·보급 위치를 보존하고, 중앙 통로를 막지 않는 작업대와 기둥을 추가했다. 실내/터널 판별도 타원형 공간을 따르며 눈 입자는 실내에 생성하지 않는다.
- `igloo-layout.ts`가 세 그래픽 등급의 공통 곡면 조각·입구·엄폐물을 정의한다. 이동은 각 조각의 보수적인 경계 상자를 사용하고, 사격·가림·시각 판정용 메시에는 동일한 실제 곡면 삼각형을 사용한다. 천장 충돌이 보이지 않는 상자에 먼저 생기던 조건을 실패 테스트로 잡아 수정했다.
- 미니맵 중앙 건물은 타원형으로 표시하고, 건물 명칭을 중앙 이글루/아치 연구동으로 바꿨다.

## 기상 규칙

서버/로컬 경기 시간 기준 120초 주기다. 일시정지한 로컬 경기는 시간이 멈추고, 온라인은 서버가 계속 진행한다.

| 경기 주기 시간 | 상태 |
| --- | --- |
| 0~60초 | 맑음 |
| 60~68초 | 폭설 강화 |
| 68~98초 | 강한 폭설 |
| 98~110초 | 폭설 약화 |
| 110~120초 | 맑음 |

강한 폭설에서는 가시거리 28m, 중간 전환은 부드러운 보간으로 적용한다. 모든 그래픽 설정에서 같은 거리 안개를 사용한다. 저사양/눈 입자 끄기는 장식 입자만 생략하며 시야 제한을 해제하지 않는다. 미니맵의 적 시각 확인·조준한 적 체력·온라인 이름표와 봇 탐지/사격도 같은 가시거리 제한을 따른다. 원래의 아군 지도 공유·핑·고층 사격 노출 규칙과 무기 사거리/피해량은 유지한다. 안개 속 예상 위치에 쏘는 행위 자체를 막지는 않는다.

봇은 범위 밖의 보이지 않는 플레이어를 새로 추적하거나 조준하지 않는다. 맵의 기상 상태와 별개로 줄어드는 눈 입자 수는 성능 옵션이며, 최대 입자 풀은 기존 160개를 재사용한다. 새 동적 광원이나 입체 안개/실시간 후처리는 추가하지 않는다.

온라인은 공개 상태 `weatherTime`을 20Hz 경기 진행에 맞춰 누적/저장한다. 기다리는 방은 0이며 체크포인트 복원 후에도 이어진다. 클라이언트는 서버 시간을 적용하므로 기기별 그래픽이나 FPS가 기상 주기를 정하지 않는다.

## 호환

설산 레이아웃 리비전은 `igloo-v1`이다. 서버는 다른 설산 구조를 가진 클라이언트의 입장을 막고 새로고침을 안내한다. 이전 체크포인트의 플레이어가 새 벽과 겹치면 점수/장비를 유지하며 안전 위치로 이동시킨다. 항구·공장·달기지의 구형 프로토콜 호환은 유지한다.

## 리소스/검증

설산 외형 삼각형: 저 10,008 / 중 13,144 / 고 17,688. 각 14개 정적 배치, RGB 질감 기본 레벨 36/72/216KiB. 이는 맵 외형 통계이며 전체 프레임 호출 수·VRAM·실기기 FPS는 아니다. 이동 판정과 곡면 사격 데이터는 품질별로 따로 바뀌지 않는다.

TDD Red를 확인한 조건:

- 이전 사각형 발자국과 실제 곡면 벽 부재
- 폭설/일시정지/품질별 기상 API 및 동일한 시야 제한 부재
- 새 맵 레이아웃과 다른 온라인 클라이언트의 입장 허용
- 실제 천장 면보다 먼저 맞는 상자 기반 사격 판정
- 폭설 속 사격만 멈추고 계속 플레이어 위치를 추적하는 봇

검증 파일: `tests/igloo-weather.test.ts`, `tests/room.test.ts`와 기존 그래픽/사격/이동/장비/성장 테스트. 실제 통로 횡단, 봇 탐지/추적/사격, 두 상태 프로토콜의 같은 기상 시간, 체크포인트 복원도 포함한다.

브라우저에서는 배포용 최적화 파일로 WebGL 1/2 × 저/중/고의 6개 조합을 검사했다. 모두 가시거리/안개 끝 28m, GPU 재질 준비, 맵 메시의 실제 그리기, 판정용 메시 숨김을 확인했다. `/workspace/qa/igloo-blizzard/`에 화면과 JSON을 보관한다. 물리 삼성/Intel GPU의 FPS 측정은 수행하지 않았다.
