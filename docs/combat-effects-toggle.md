# 전투 시각 효과 켜기/끄기

환경설정 → 그래픽 → 전투 시각 효과 켜기를 제공한다. 높은 화질에서도 선택할 수 있고 다른 화질에서도 같은 선택을 유지한다. 기존 사격 효과의 안정/전체 선택과 독립적이며, 켜면 기존에 선택한 효과 수준을 사용한다. 브라우저에 저장하고 맵 변경 때 재적용하며 기본값 복원은 켜기로 돌아온다.

끄면 내 총과 상대 총의 총구·탄도·명중 불꽃, 탄피·먼지·탄흔, 로봇 피격 입자, 수류탄/로켓 폭발 장식을 없앤다. 날아가는 장비의 모형·실제 피해·탄약·소리·처치 자세와 섬광탄 실명은 유지한다. 진행 중 효과는 즉시 지우고 끈 동안의 폭발은 다시 켤 때 재생하지 않는다.

TDD: 저장 값 누락과 끈 뒤에도 사격 효과가 발생하는 실패를 먼저 확인했다. 저장/초기화, 효과 해제·재활성화, 과거 폭발 재생 차단, 투사체 모형 유지, 높은 화질의 실제 장면 사격/탄약/효과 전환 검사를 통과했다. 삼성 인터넷 실기기 체감과 실제 GPU 프레임은 별도 확인 대상이다.
