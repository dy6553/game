# 무기 7종·모바일 시점·엄폐물·적 출현 개선 — 2026-11-08

사용자가 기관단총·3점사 소총·반자동 소총 추가와 사진의 시점/터치/AI 출현/엄폐물 개선을 요청했다. 아래 전투 수치는 추천안을 확인받고 확정했다.

| 무기 | 피해 | 탄창 | 발사 | 재장전 |
|---|---:|---:|---|---:|
| 기관단총 SMG | 7 | 40 | 초당12발, 연사, 근거리용 퍼짐 | 1.8초 |
| 3점사 소총 | 발당18 | 24 | 한 번 누르면3발, 내부0.08초, 점사 시작 간격0.65초 | 2초 |
| 반자동 소총 | 50 | 10 | 한 발씩, 간격0.5초, 확대 없음 | 2.2초 |

기존4종과 합쳐7종이며 시작 무기 선택·게임 안 선택창·로비3D 총·보급 상자·최대3개 소지·슬롯 교체·공식 온라인 서버 판정에 연결한다. 새 상자는 기존 상자와 같은 획득 거리/20초 재보급 규칙이다. 기존 Kenney 음원 외 새 외부 에셋/서비스는 없으며 새 총소리는 합성한다.

점사는 실제 탄약을 한 발씩 소비하며 버튼을 떼도 해당3발은 마무리한다. 다시 누르기 전 다음 점사는 반복하지 않는다. 재장전/무기 교체/사망/온라인 연결 해제는 대기 중 점사를 취소한다. 오프라인 메뉴 정지는 점사 시간을 동결한다. 서버는20Hz 틱에서 처리하므로0.08초 간격은 다음 유효 틱에 실행한다. SMG는 틱의 남은 시간을 반영해 연사율이10발/초로 줄지 않도록 했다.

## 사진 요청

- 모바일 기본 시점 회전을0.004→0.007rad/px로1.75배 높였다. 기존 감도 배율 저장과 PC 마우스 감도는 유지한다.
- pointerup/cancel이 캔버스 밖에서 끝나 lookPointer가 남으면 다음 드래그가 무시되는 문제를 재현했다. 전역 종료 이벤트에서 일치하는 손가락만 정리하고 캡처가 끊긴 이동도 이어받는다. 조이스틱/발사 손가락을 함께 해제하지 않는다.
- 소지품 HUD의 배경/문구는 시점 터치를 통과시키고 실제 버튼만 조작을 받는다.
- 지상 개방 구간에 컨테이너·화물·설비/기념 구조물 형태의 엄폐물6개를 추가했다. 높이2.2~2.6m, 서버/로컬 이동·총알 충돌을 일치시켰다. 출입 가능한6개 건물 입구 경로는 유지한다. 추가 조명/텍스처/유료 에셋 없음.
- 봇 부활과 생존 증원 대기는3→1.5초. 생존 첫 웨이브 총 적은3→4명, 매2웨이브 증가·최대12·동시최대3명과 총 웨이브 수는 유지한다. 플레이어 부활3초와 온라인1대1 승패/부활 규칙은 유지한다.

## 검증

터치 두 번째 드래그 누락·느린 기본 감도, 엄폐물 누락, 무기4종/점사 미구현·기존3초 적 부활의 의도한 assertion 실패를 먼저 확인한 후 구현했다. 전체169개/44파일 통과. 새 규칙과 무관한 기존 전투 검사도 유지하고 무기 수/생존 할당/봇 대기 fixture만 승인 수치에 맞췄다.

PC/모바일 DOM에서7종 선택·출격·이름 표시, 기존 획득/교체/문/확대 동시 터치 검사를 통과했다. 실제 Chromium에서 조이스틱을 잡은 채 시점 드래그10회가 모두0.14rad/20px로 처리되고 이동이 유지됨, HUD 터치 통과, 새 엄폐물 앞면의 실제 광선 차단, 런타임 예외0을 확인했다. 실제 Chromium에서 새3종 선택·출격·발사 후 SMG39/점사21/반자동9발, 보급 상자7개, 예외0도 확인했다. 실제 Android 체감과 장시간 성능은 별도다.

운영 배포와 공개 서버 검사는 릴리스 실행 기록과 구분한다. 브라우저 QA용 상태 노출은 로컬 응답에만 넣으며 배포 소스에 포함하지 않는다.
