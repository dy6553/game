# 시점 회전의 끊김 추가 개선 — 2026-11-09

사용자는 이전 배포 뒤에도 화면 전환이 부드럽지 않다고 답했고 추가 수정을 요청했다. 이번 변경은 화면을 그리는 비용과 건너뛴 프레임의 반복 처리에 한정한다. 기존 마우스 감도·밝기·게임 규칙·서버 판정·온라인20Hz 입력은 유지한다.

## 변경과 확인 근거

- 원격 로봇의 기존 색을 꼭짓점 색에 담고 발광색별로 묶는다.19명 본체가152개→57개 메시가 됐다. 모든 꼭짓점·색상·발광 표면을 유지하며,다른 로봇이 맞았을 때 함께 번쩍이지 않는 검사도 통과했다.
- 같은 종류와 자세의 로봇은 숨긴 원형을 공유한다.19명 동일 로봇의 본체 기하 데이터가152개→3개가 됐다. 피격용 재질은 각 플레이어 전용이다. 경기 종료 시 원형과 기하 데이터를 정리하고 반복 입장 후 메시/재질 수를 복원한다.
- 실제로 그릴 프레임에서만 온라인 메시·시각 효과를 갱신한다. 로컬 이동 예측과 입력 송신은 화면 제한과 별도로 계속한다.30FPS 검사에서 시각 갱신30회와 네트워크 약20회가 각각 유지된다.
- 자동 화질과 진단FPS는 화면을 건너뛴 콜백을 세지 않는다. 콜백80Hz/실제 화면 약40Hz 재현에서 이전에는 자동 해상도가 내려가지 않았다. 실제로 그린 화면 간격을 사용한 뒤 자동 대응과 진단 표본 수 검사가 통과했다. 이전 커밋의 진단FPS는 콜백 기준이므로 새 진단과 그대로 비교하지 않는다.
- 설정이나 숨겨진 탭에서 수신한 시각 이벤트를 쌓았다가 한꺼번에 재생하지 않는다. 화면을 그리는 일반 경기의 낮은FPS에서는 기존 유한 이벤트 큐가 계속 보존하며,사격·탄약·피해 결과는 서버 최신 상태를 따른다.
- 저부하 프로필은 표면 법선맵 샘플링을 생략하고 텍스처 필터를2단계로 낮춘다. 원래 색상 텍스처·간접광·실내 밝기는 유지한다. 높음으로 돌아오면 원래 법선맵과8단계 필터를 복원한다.

## 측정의 범위

같은1280×720 Chromium20인 배치에서 그리기 호출은 균형649→459회,저부하311→216회였다. 브라우저는SwiftShader이므로 이를 Intel Graphics의FPS 향상률로 말하지 않는다.

별도 고정 커밋 작업 폴더와 현행 소스에서 NullEngine 상대19명 생성/정리를 각각1회 준비 후6회 측정했다. 중앙값395.45→82.12ms,표본 최대574.68→86.48ms였다. 로컬CPU 장면 생성 비용 비교이며 GPU·실제PC 프레임·장시간 안정성을 측정한 것이 아니다. 초기 다른 부하가 함께 있던 표본445→228ms와 구분한다.

## TDD와 검증

구현 전에 본체 그리기152회 상한 실패,30FPS에서 시각 갱신60회 실패,숨긴 설정 복귀의 오래된 이벤트1개 실패,실제40Hz를 콜백80Hz로 판단하는 실패를 실행했다. 진단 표본도 실제 그리기 수와 다름을 먼저 실패로 확인했다. 최소 수정 뒤 동일 검사들이 통과했다.

추가 법선맵 검사의 초기 실패 객체 출력은 메모리 한도 때문에 종료137이 발생했으며 기능Red로 세지 않았다. 단언 출력을 boolean으로 줄이고 고정된 이전 커밋에서 실제 assertion 실패를 확인한 뒤 현행 통과와 비교했다.

- 전체275개/74파일 회귀 검사 통과.
- PC·모바일 DOM에서 각각 사격 보존3개와 프레임 처리3개 검사 통과.
- 원래 색상·발광·모든 꼭짓점 보존,피격 효과 분리,경기 종료 후 기하 정리 검사 통과.

## 통합 그래픽 GPU 부하 후속 조정

이전 자동 해상도는 지속적으로 목표 프레임보다 낮아져도 DPR 0.5에서 멈췄다. GPU 병목을 호소하는 기기에서 화면 픽셀 부하를 더 줄일 수 있도록 자동 모드의 하한을 DPR 0.35로 낮췄고, 수동 저화질은 DPR 0.45로 낮췄다. 자동 모드는 프레임이 목표치의 85% 미만인 구간이 지속될 때 단계별로 해상도를 내리고, 충분히 안정된 뒤에만 천천히 올린다. DPR 0.35는 DPR 0.5 대비 픽셀 수가 약 51% 적지만 화면이 더 흐려진다.

TDD 검사는 새 GPU 압력 하한을 먼저 실패시킨 뒤 수정 후 통과했다. 전체276개/74파일 검사, 타입/Vite 빌드, `git diff --check`가 통과했다. 이 테스트 환경은 실제 Intel Graphics GPU 프레임 시간을 측정하지 않으므로 실기기 효과는 여전히 해당 PC에서 확인해야 한다.

게시 대상은 사용자 승인으로 연결한 `dy6553/game`의main과 기존 `https://project-3uu6s.vercel.app/`다. 새 서비스·비용·DB 변경은 없다. 실제 배포 커밋과 공개 파일 검증 결과는 작업 완료 응답을 따른다. 사용자 Intel PC에서의 실제 회전 체감과FPS는 별도 확인이 필요하다.
