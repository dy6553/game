## 변경

- 고정 지형의 격자 통과/선분 충돌 판정을 재사용한다. 지상 선분 캐시는 최대16,384개, 정적 계단 연결은 최대1,024개로 제한한다. 문을 열어 둔 상태의 계획용 지형만 캐시하며 실제 이동은 현재 문 충돌을 계속 검증한다.
- 옥상 경로의 고정 계단 연결과 같은 질의 안의 중복 계산을 재사용한다. 반환 경로는 호출자 소유 복사본으로, 수정해도 이후 경로나 공유 계단이 바뀌지 않는다.
- 계단·층별 바닥 형상은 불변 데이터로 재사용한다. 사격 장애물은 문 상태별로 재사용하고 문을 열고 닫으면 즉시 해당 상태의 형상을 선택한다.
- 폭이 좁은 도로에 긴 변 길이 기준의 정사각 격자가 들어가던 것을 가로/세로 각각 최대2m 격자로 바꿨다. 지형 경계·텍스처 좌표·기존 조명 샘플 함수는 유지한다.
- 지난 엄폐물 추가에서 화단용 나무·벤치가 새 화물/설비에도 생성되던 것을 원래 화단3개에만 적용한다. 엄폐물6개 자체와 충돌은 유지한다.
