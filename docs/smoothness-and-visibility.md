# 마우스·다인 모드·야간 가독성 개선 — 2026-11-09

사용자가 Core Ultra5 245K·RAM16GB·Intel Graphics에서도 다인 모드가 끊기며 마우스 감도와 어두운 외곽/실내를 개선해 달라고 요청했다. 이 문서가 해당 부분의 이전 감도·자동 화질 기준보다 우선한다.

## 변경

- PC 감도는0.10~3.00배,0.01배 단위로 저장한다. 클릭 없는 조준과 마우스 고정 조준 모두 픽셀당0.0025rad를 기준으로 사용한다. 이전 일반 조준0.004rad보다37.5% 낮으며, 기존 사용자 배율은 유지한다. 저격 확대 중 PC 감도는0.3배를 곱하고 해제 즉시 복원한다. 추가 평활 지연은 넣지 않았다. 모바일 감도·다중 터치·상하 반전은 유지한다.
- 자동 화질은 PC에서도 DPR 상한1·균형 상세도로 시작한다. 수동 높음은 기존 상한2를 유지한다. 목표FPS의85% 미만이2초 지속되면 해상도를 낮추며,95% 이상이3개 창 지속돼야 회복한다. 기본60FPS에서40FPS인 경우에도 대응한다. 목표FPS는 실제 성능 보장이 아니다.
- 그림자맵은 균형1024·높음2048을 유지한다. 온라인 상대의 그림자는 균형24m·높음40m 이내에서만 생성하며, 저부하 프로필에서는 제거한다. 캐릭터·이름/체력 판정·전투·충돌·20인 정원은 거리로 삭제하지 않는다.
- 같은 저부하 설정을 매 프레임 다시 적용하지 않는다. 장식 visibility 쓰기는 로컬330프레임 비교에서9570회→0회였다. NullEngine20인 CPU 중앙값은0.160→0.189ms로, 이 표본에서 CPU 시간 개선은 확인되지 않았다. GPU/실기기FPS와 혼동하지 않는다.
- 미확인 입력마다50ms를 부여하던 로컬 이동 재생을 실제로 예측한 경과 시간으로 바꿨다.16ms 입력3개/48ms 재현의 불필요한 보정0.714m가 제거됐다. 서버 위치·피해·승패 권한은 그대로다.
- 사격·장비 시각 이벤트를 최신 상태와 분리해 유한 큐로 보존한다. 큐당 최대512개,ID중복 제거·소비 후 비움·세션/홈 복귀 초기화를 적용한다. 다음 스냅샷이 먼저 도착해도 사격 효과·명중 HUD를 유지한다.
- 외곽 지면의 구운 조명 하한, 하늘/바닥 방향의 간접광, ambient·노출을 높이고 대비를 완화했다. 가로등의 따뜻한 색과 푸른 그림자를 유지한다. 동적 조명 수는13개로 늘리지 않았고 저부하에서도 밝기 개선을 유지한다.
