# 최적화·높은 화질 효과·BGM·조작 편집·전투 검증

사용자는 기본 최적화, 높은 화질에서 다양한 효과, 기본 BGM 및 앞선 추천의 나머지 항목(거리별 무기 밸런스 검증, 온라인 명중/지연 점검, 화면 버튼 드래그/겹침 안내/기기별 배치, 재장전/무기 교체 연출)을 요청했다.

## 성능과 높은 화질

투사체 80개가 하나의 기하를 공유하고 회전용 Quaternion/벡터를 재사용한다. 문 상태가 바뀔 때만 문 메시/맵 모델에 반영하며, 표적 피격 색은 기존 Color3를 재사용한다. 오디오 전경 상태가 같으면 매 프레임 GainNode에 같은 예약을 반복하지 않는다. 자세 표시와 일시정지 문구도 값이 바뀔 때만 갱신한다.

‘높음’ 화질 + ‘전체’ 사격 효과 + 전투 시각 효과 켜기에서 폭발 충격파·불꽃·연기·로켓 잔상과 더 풍부한 명중 불꽃을 표시한다. 추가 투사 조명·실시간 반사·전체 화면 후처리는 없다. 장비 장식은 입자32/고리4 풀을 재사용하고 사격 불꽃도 기존48 풀 안에서 처리한다. 낮음/균형 또는 안정 효과로 전환하면 장비의 추가 장식을 즉시 지운다. 전투 시각 효과 끄기와 플레이에 필요한 투사체 모형 유지는 기존대로다.

검사에서 투사체 기하 공유 수 80→1, 30프레임의 같은 문 상태에 대한 rotation 쓰기 0회, 반복 폭발 후 메시 수 고정을 확인했다. 이는 기하/갱신 비용의 증거이며 실제 삼성 기기 FPS 개선률이 아니다.

## BGM

직접 만든 Harbor Pulse 반복곡(약20초, 157KiB MP3)을 추가했다. scripts/create-bgm.py로 재생성할 수 있으며 기존 곡/샘플을 사용하지 않았다. 첫 사용자 조작으로 브라우저 오디오가 해제되면 기본 재생한다. 전투에서는 BGM만 35%로 낮추고, 전경을 벗어나거나 전체 음소거 시 들리지 않는다. 별도 BGM 켜기/음량은 환경설정에 저장한다. 파일 로딩 실패는 게임을 막지 않는다. 효과음 24개 제한·방향/거리 감쇠·우선순위는 유지한다.

## 거리별 피해와 온라인

최대 피해와 헤드샷1.5배/강화에서도 체력100 단발 즉사 방지를 유지한다. 사거리 시작~끝 사이를 선형 감쇠하고 이후 최저 비율을 유지한다. 서버/봇전/연습이 같은 rangedDamage 함수를 사용한다.

| 무기 | 감쇠 시작~끝(m) | 최소 비율 |
|---|---|---|
| 권총 |40~80|75%|
| 기관총 |35~80|80%|
| 기관단총 |12~36|55%|
| 산탄총 |8~28|35%|
| 3점사 |40~80|80%|
| 4점사 |35~80|75%|
| 반자동 소총 |55~110|85%|
| 저격총 |100~150|90%|

바주카는 기존 비행·폭발 거리 감쇠를 유지한다. 온라인 20Hz 때문에 기관총8발/초가 실제1초에서7발로 줄어드는 실패를 재현했고, 남은 발사 시간의 초과분을 자동화기에서 재사용해8발을 발사하도록 수정했다. 같은 계산을 오프라인에 적용한다. 틱/입력 송신 주기·서버 피해 확정·벽/층 차폐·부활 보호·이벤트 중복 차단은 유지하며 관련 회귀를 검사한다. 서버 되감기 판정이나 새 네트워크 프로토콜은 도입하지 않았다. 실제 인터넷 지연 감소·태블릿 GPU 병목 해소를 보장하지 않는다.

## 화면 조작과 연출

환경설정 → 조작에서 화면 버튼을 드래그하고 크기를 조절하는 편집 화면을 추가했다. 실제 게임 조작을 차단한 편집용 버튼을 사용하며 저장하고 돌아가기로 닫는다. 버튼끼리 겹치면 점선·문구로 표시한다. 문/획득은 원래 서로 배타적이므로 두 안내끼리의 겹침은 제외한다. 드래그 중에는 미리보기만 움직이고 놓을 때 저장한다. 취소하면 이전 위치로 돌아간다. 태블릿/휴대폰/PC 프로필은 화면 배치를 따로 저장하고 키보드 설정은 공유한다. 기존 저장 배치도 이전한다.

재장전 진행률에 맞춰 총을 내리고 탄창/손을 움직여 복귀하며, 교체 시 짧게 내렸다 올린다. 서버 온라인 재장전 값도 사용한다. 조준·실제 탄약·교체/재장전 타이머는 연출 때문에 달라지지 않는다. ‘동작 줄이기’ 환경에서는 움직임 크기를 줄인다.

## 검증

TDD에서 거리 감쇠 누락, 기관총7발/초, 연출 변위 없음, BGM 기본값 없음, 투사체80개 별도기하, 프로필 API 누락의 실패를 확인한 뒤 수정했다. 전체 자동검사 343개와 운영 빌드, 실제 Chromium에서 BGM 기본/끄기/전투 음량 감소, 드래그·겹침·크기·프로필 저장/새로고침 유지, 높은 화질 추가효과14개→낮음0개, 재장전 총 위치/탄창 표시 및 페이지 오류 없음을 확인했다.

실제 삼성 인터넷/Intel GPU의 FPS와 발열 및 온라인 인터넷 RTT는 측정하지 않았다. 현재 성능 진단 링크를 사용해 같은 조건에서 실제 기기 측정이 필요하다. 외부 유료 서비스·사용자 식별 정보 수집은 추가하지 않았다.
