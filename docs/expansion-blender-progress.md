# Blender 추가 맵 제작 기록 — 2026-11-15

## 확인한 현재 구조
- 실제 앱은 game-local의 1인칭 Babylon.js 게임이다. 상위 폴더의 탑다운 문서는 이전 기획이므로 그대로 구현에 적용하지 않는다.
- world.ts는 harbor/factory만 허용한다. scene.ts·main.ts·network-game.ts에도 두 맵을 전제로 하는 분기가 있다.
- 그래픽은 이미 자동/높음/균형/낮음과 저장 기능이 있다. 이번 상/중/하 및 중 기본값 요구와 맞추는 작업이 필요하다.
- 기존 앱에는 4종보다 많은 무기, 장비, 성장 해금과 다인 온라인이 있다. 이번 맵 기획이 기존 기능 삭제를 의미하지 않는다.
- 이번에 승인한 상자 30초·바닥 무기·부활 5초 등은 기존 동작과 다르므로 별도 동작 테스트 후 연결해야 한다.

## 이번에 제작한 것
- Blender 5.2.3의 설치된 연결 애드온을 활성화해 제어 연결을 확인했다.
- 기본 장면을 지우지 않고 별도 장면 Expansion asset workshop을 생성했다.
- 보급 상자·연구 콘솔·금속 운반 상자·달 화물 상자·달 탐사 장비·고정 발전기 6종을 직접 모델링했다.
- art/expansion/expansion-assets.blend에 저장했다. 같은 폴더에 미리보기 PNG와 각 소품의 GLB를 내보냈다.
- 외부 에셋·텍스처·폰트·유료 생성 서비스는 사용하지 않았다. 모든 모델은 이번 작업에서 직접 생성했다.
- 미리보기 렌더를 확인하고 소품 배치의 부모 변환 중복을 수정했다.

그리기 단위는 GLB의 메시 참조별 프리미티브 수이며, 그림자·캐릭터·장비 등을 포함한 실제 프레임 전체 호출 수나 FPS가 아니다.

검증: 새 눈 효과가 없어서 실패하는 테스트를 실행한 후 구현했다. 눈 효과 관련 3개 검사는 통과했다. 6개 모델의 질감 해상도·품질별 장식 예산·필수 랜드마크 유지와 기존 배치 검사는 통과했다. 사용자의 발열 요청에 따라 전체 게임 검사·Blender 렌더링은 실행하지 않았다. Blender 작업은 백그라운드에서 한 개 프로세서·낮은 우선순위로 실행한 뒤 종료했다.

여기서 눈 효과는 **시각적인 가벼운 강설**이다. 불규칙 눈보라의 시야 제한·봇 인식, 시간대 순환, 달 저중력과 파괴 가능한 엄폐물·잔해 게임 규칙은 아직 미구현이다. 실기기 FPS/발열과 실제 온라인 경기 수용 검증·배포도 완료하지 않았다.

### 이번 수정의 최종 확인
