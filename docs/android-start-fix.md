진단 도구는 왼쪽 위의 접이식 작은 버튼으로 이동했다. 기본은 진단 코드/전송 횟수만 표시하고 펼치면 기존 상태·수집 끄기·기록 저장을 제공한다. 기본 주소는 계속 수집하지 않고 `?diagnostics=1`에서만 수집한다. 기록 필드/전송/개인정보/보존 정책은 바꾸지 않는다.

짧은 가로 화면은 로비 그리드 행을 가용 높이 안에 제한하고 장비/매치 설정을 내부 스크롤로 표시한다. 시작 영역은 매치 패널 아래에 sticky로 유지해 설정 내용이 길어져도 게임 시작을 누를 수 있게 한다. 일반 화면의 로비 구조는 유지한다.
