# 장비·랜덤 보급·20인 온라인

2026-11-08 사용자 요청과 추천 규칙 승인. 사용자 정정으로 개인전은 같은 맵에서 최대20명이 동시에 경쟁한다. 대진표/탈락 라운드는 없다.

## 경기

- 온라인1대1 유지(10킬), 개인전2~20명(먼저10킬), 팀전 최대10대10(팀 합계30킬).
- 팀은 인원수가 적은 쪽으로 자동 배정. 아군 총알은 아군에게 막히지만 피해는 없고, 아군 수류탄·섬광 효과는 제외한다. 자기 투척 효과는 적용한다.
- 두 명 연결 시 시작, 팀전은 양쪽 팀 연결 필요. 정원까지 중도 입장한다. 자동 매칭은 모드·맵별로 구분한다. 초대 코드는 방의 실제 모드를 따른다.
- 개인별30초 재접속 유예, 한 명 퇴장/연결 종료로 다른 참가자의 경기를 닫지 않는다. 대전 상대가 부족한 상태가2분 지속하면 무승부 종료(공식 정산 없음). 시작 전 대기는10분, 완료 결과는1분 후 방 정리.
- 동시 정원20명에는 경기 중 이탈자도 포함한다. 새 인원이 기존 이탈자 슬롯을 대체하지 않는다. 같은 계정 중복 입장은 계속 금지한다.
- 플레이어 사망3초 후 야외 분산 부활,3초 보호. 사격/투척 시 보호 해제. 폐공장 온라인 Lv3 제한과 기본 무기 성능은 유지한다.
- 순위표에 접속 인원·킬/데스·팀·이탈 상태 표시. 경기 이동/명중/HP/킬/팀 점수/승패/장비는 서버가 확정한다.

각각 최대2개, 무기3칸과 별도. 상자에서만 획득하며 사망 시 모두 잃는다. 연속 사용 방지0.8초. PC G/B/H, 모바일 전용3버튼을 사용한다. 투척물은 공통 월드 벽·문·층 바닥과 충돌/반사하며80개 풀, 폭발 표시는8개 풀을 재사용한다. 점프 높이를 포함해 던지고 피해를 계산한다. 연습/봇전에서도 장비와 자기 피해·회복을 지원한다.

## 보급

경기마다 무기7종+장비3종 총10상자를 새 위치에 배치한다. 야외·실내1층·2층을 포함하고 옥상은 제외한다. 가구·벽과 겹치지 않고 서로4m 이상 떨어진 후보를 사용한다. 획득 후20초 뒤 같은 위치 재보급. 사망·생존 웨이브 변경으로 위치를 재추첨하지 않는다. 완전 재시작/다음 경기만 재추첨한다. 상자 시각 메시도 새 좌표/층을 따른다.

기존 고정 위치를 전제로 한 단위 장면 검사에서는 `randomSpawns:false`/기본 네트워크 생성 fixture를 유지한다. 실제 Scene 기본값과 Worker 예약은 랜덤10상자를 사용한다.

## 저장·성능

완료한 로그인 참가자의 공식 전적·XP를 기존 Neon 저장 경로로 정산한다. 최근 기록에 duel/ffa/team을 추가하고 팀전30킬 이상 데스를 저장하도록004마이그레이션을 적용한다. 서버의 지연 전송·영수증 중복 방지·탈퇴 cascade 유지. 마이그레이션은 서버의 기존 DB 권한으로 최초 접근 때 적용하며 DB 접속정보를 클라이언트에 보내지 않는다. 유료 서비스/플랜/외부 에셋은 추가하지 않았다.

상대 모델은 낮은 기하 세분화와 재질별 메시 병합을 사용한다. 모든19명을 표시하면서 반복 진입 시 메시/재질을 정리한다. 순위표 행은 표시 값 변경 때만 갱신한다. 모바일 FPS를 보장하는 기능은 아니다.
