# 사운드 개선과 모바일 안정성 검증 — 2026-11-07

사용자가 다음 단계 진행과 소리 업그레이드를 요청했다. 다음 수용 단계인 Android 로그인·재접속 확인과 병행해 기존 사운드를 개선한다. 새 서비스·패키지·외부 음원은 추가하지 않는다. 기존 Kenney CC0 MP3 10개를 유지하고 새 효과음은 코드로 합성한다.

## 변경

- 온라인 상대 총소리에 청취자 위치/시점 기준 좌우 방향과 거리 감쇠를 적용한다. 자기 총소리는 중앙이다.
- 같은 서버 틱의 산탄총 탄환들을 한 발 소리로 묶고 명중/처치 확인음도 가장 강한 결과 하나만 낸다.
- 서버가 확정한 자기 재장전/완료·피격/사망/부활·점프/착지·발소리·대시·획득·교체에 소리를 연결한다. 오프라인 대시·획득·교체도 연결한다.
- 새 대시 바람음·획득 상승음·교체 기계음과 서로 구분되는 재장전/완료·점프/부활·사망 합성음을 제공한다.
- 최초 입장·재접속·백그라운드 동안 받은 상태는 기준으로만 저장해 과거 효과음을 몰아 재생하지 않는다. 순간이동/공중/대시 이동은 발소리에서 제외한다.
- 동시 전투 소리는 최대24개, 메뉴 소리는 최대4개를 유지한다. 피격·명중·처치 등은 낮은 우선순위 발소리/탄착음을 교체할 수 있다.
- 모바일 AudioContext 중단은 다음 터치/키 입력으로 다시 resume한다. interactive 지연 힌트를 사용하며 실제 지연 감소 수치를 보장하지 않는다. 음소거 시 진행 중 효과음을 버리고 dispose 이후 지연 콜백이 재시작하지 않도록 한다.
- 도움말 소리 설정의 ‘좌우 소리 확인’은 왼쪽→오른쪽 짧은 테스트음을 재생한다. 기존 전체/효과음/환경음·음소거 저장을 따른다.

## Android에서 남은 수용 확인

1. 기존 게임 링크를 새로 열어 로그인하고 온라인 방에 입장한다. 출격 버튼·모바일 입력·전적 버튼이 가리지 않는지 확인한다.
2. 이어폰으로 도움말 → 소리 → 좌우 소리 확인을 누른다. 총소리 방향·크기, 점프/대시, 재장전/완료를 확인한다.
3. 앱을 잠깐 전환했다 돌아와 화면을 누른다. 소리가 복구되고 과거 총소리가 몰려 나오지 않아야 한다.
4. 30초 이내 잠깐 연결을 끊었다 복귀해 방 복구·조작을 확인한다. 두 실제 기기/다른 인터넷의 장시간 경기·발열·이어폰 지연은 사용자 기기에서 확인해야 한다.
5. 온라인 경기 종료 후 공식 전적을 확인하고 로그아웃/로그인을 확인한다. 비로그인 경기는 공식 전적에서 제외되는 기존 규칙을 유지한다.

경험치·실력등급 계산은 PRD의 미정 규칙이므로 이번 수용/사운드 작업에 추가하지 않는다.
