# 문·2층·옥상·몹 이동과 부활 보호 — 2026-11-07

사용자가 문 열기, 2층/옥상, 야외 랜덤 몹 생성, 부활 직후 몰림 완화, 몹 이동 개선을 요청했다. 추천 규칙 전체를 승인하고 출입 가능 건물 표시를 추가 요청했다.

## 적용 규칙

- 출입 가능한 기존 6개 건물에 초록 입구 프레임·바닥 표시·‘출입 가능 · 2F / 옥상’ 간판을 단다. 나머지 건물은 장식/충돌 건물이다.
- E / 모바일 문 버튼으로 열고 닫는다. E 범위에 획득 가능한 상자가 있으면 획득을 우선한다. 문은 처음에 닫혀 있고 자동으로 닫히지 않는다. 닫힌 문은 이동과 사격을 차단한다. 가까이 있는 몹도 문을 열며 살아 있는 캐릭터를 끼워 닫을 수 없다.
- 서쪽 계단은 지상→2층(3.4m), 동쪽 계단은 2층→건물별 높이의 옥상으로 연결된다. 플레이어와 몹 모두 사용한다. 옥상 가장자리는 난간으로 막고 별도 낙하 피해 규칙은 추가하지 않는다.
- 높이와 계단 지지면을 공통 좌표로 계산한다. 벽·층간 바닥·계단·닫힌 문·난간의 사격 장애물과 플레이어 높이는 온라인 서버가 판정한다. 위층에서 아래층의 상자를 줍지 못한다.
- 실제 게임의 몹 최초 생성/증원/부활은 야외 지상에서만 랜덤 배치한다. 건물 영역과 충돌물·경계 바깥을 제외하고 플레이어/살아 있는 몹과 최소12m 떨어진 후보를 고른다. 유효 후보가 없으면 가장 멀리 떨어진 후보에서 선택한다. 단위검사의 기존 전투 장면은 명시적으로 고정 생성 fixture를 주입한다.
- 플레이어는 적과 먼 안전 후보에서 부활하고 3초간 피해를 받지 않는다. 실제 사격이 발생하면 보호를 즉시 해제한다. HUD에 남은 시간을 표시한다. 최초 출격 보호는 추가하지 않는다. 오프라인 정지는 시간을 멈추며 온라인은 서버 시간에 따른다.
- 몹은 장애물을 피하는 대각 경로와 직선 경로 정리, 계단 연결 경로, 접근한 문 열기, 근거리 후퇴·다른 캐릭터와 간격 벌리기를 사용한다. 기존 난이도별 조준/경고/속도와 경고 중 정지·벽 뒤 회피를 유지한다. 봇끼리 공격하지 않는다.

## 검증과 한계

부활 보호 0회/기대3초, 문 상태/계단/야외 생성 미구현 assertion 실패를 먼저 확인한 후 구현했다. 기존 회귀 fixture는 승인된 랜덤 생성·먼 곳 부활·보호 규칙에 맞춰 갱신했으며 보호 해제/만료는 별도 검사한다.

전체158개/41파일·PC/모바일 DOM·타입/운영 설정 웹 빌드·Worker dry-run 빌드가 통과했다. 추가 자동 검사는 문 거리/끼임 방지, 모든 건물 두 계단의 상승, 야외 생성 분산, 세 봇 모드의 보호, 서버 문 one-shot·계단·보호, 층간 탄환 차단/동층 명중, 실제 장면의 동적 문 보존/간판6개, 몹의 문 열기와 옥상 도달, 몹 간격을 검사한다. PC/모바일 DOM에서 기존 이동 중 획득·교체·확대, 문 동시 터치/중복 방지/서버 확정 라벨도 확인한다.

실제 Chromium 844×390 터치: 문 열기/건물 진입, 2층·옥상 바닥/카메라 높이, 간판6개, 런타임 예외0을 확인했다. 브라우저 응답에만 QA 위치 제어 브리지를 넣었으며 배포 소스에는 포함하지 않는다. 물리 Android 조작감·장시간 발열/성능은 별도다. 클라우드 소프트웨어 렌더링의 FPS를 휴대폰 성능으로 보고하지 않는다.

운영 배포/실서버 연결은 릴리스 실행 결과와 구분한다. 기존 계정/전적 DB·과금·외부 에셋/서비스는 변경하지 않는다.
