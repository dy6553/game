# 온라인 안정화 — 2026-11-06

## 수정

- 두 사람이 끊긴 뒤 한 명만 돌아와도 최초 연결 끊김의 30초 기한을 유지한다. 다시 끊기거나 한 명만 재접속하는 것으로 기한이 연장되지 않는다.
- 두 소켓이 모두 닫혀 갱신 루프가 멈춘 상태에서도 30초가 지난 재접속은 거절하고 방을 종료한다.
- 서버 체크포인트에 경기 시작·종료·연결 끊김 시각과 경기 시작 여부를 함께 저장한다. 서버 복구 때도 해당 기한을 유지한다.
- 모바일 낮은 화질에서 온라인 상대의 처치 효과도 기존 16개 상한을 따른다. 화질을 바꾸면 현재 상대에게도 적용한다.

검증: 실제 Worker Room 클래스를 가상 시간·소켓·저장소에서 실행하는 재접속 회귀 검사 3개 추가. 전체 자동 검사 52개, 웹 빌드, Worker dry-run 및 모바일 DOM 검사 통과. 공개 서버 두 WebSocket 회귀 검사는 배포 후 별도로 확인한다. 실제 GPU/휴대폰 간 조작·발열·서로 다른 인터넷 지연 확인은 아직 완료로 처리하지 않는다.

## 실제 두 기기에서 확인

1. 첫 기기에서 온라인 → 방 만들기, 두 번째 기기에서 코드로 입장.
2. 각 기기에서 상대 이동·점프·발사와 벽 뒤 피격 차단, 탄약·재장전 확인.
3. 처치 후 3초 부활과 10킬 종료, 홈 복귀 후 새 방 입장 확인.
4. 휴대폰에서 이동·시점·발사 동시 터치, 세로 회전·가로 복귀, 앱 전환 후 입력이 멈추는지 확인.
5. 한 기기의 네트워크를 잠시 끊었다가 30초 안에 복구해 동일 점수·체력으로 돌아오는지 확인. 30초가 지나면 종료 안내 확인.
6. 와이파이와 모바일 데이터처럼 서로 다른 네트워크에서도 확인. 지연·끊김·발열은 기기/브라우저/상황과 함께 기록.

실제 기기를 사용할 수 없는 환경의 자동 검사는 이 목록을 대체하지 않는다. 무기 획득·대시·새 AI 규칙은 이번 안정화 범위에 추가하지 않는다.
