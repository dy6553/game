# 녹화 제보: 총·손 겹침 수정 — 2026-11-13

사용자가 제공한 삼성 인터넷 녹화(1728×1080, 약 4.17초)의 노란 표시를 확인했고, 사용자가 ‘총·손 모양이 깨지거나 겹쳐 보임’이라고 특정했다.

## 수정

- 손바닥보다 카메라 쪽으로 돌출된 검은 손잡이가 장갑을 가리던 배치를 수정했다. 손바닥에 기존 장갑 재질을 적용하고 손가락을 손잡이 옆에 세로로 배치해 한 덩어리로 잡도록 했다. 손목도 손바닥과 이어지는 위치로 조정했다.
- 하부 총몸이 상부 총몸에 파고들던 부피 중첩을 제거했다. 같은 위치에 겹쳐 생성한 슬라이드 레일 하나도 제거했다.
- 재장전 시 손바닥 메시만 회전시키던 처리를 제거했다. 기존 전체 총·손의 재장전/반동 변환은 유지해 손가락과 손목이 분리되지 않는다.
- 무기 교체로 총열 길이가 바뀌면 총구와 총구 안쪽도 실제 총열 끝을 따라가도록 했다. 산탄총 두 번째 총열 끝도 첫 번째와 맞췄다.

메시 수·렌더 패스·조명·외부 에셋을 추가하지 않는다. 총의 전투 판정 광선·피해량·장비·온라인 권한·조작 배치는 유지한다. 총구에서 시작하는 시각 효과는 수정한 총구를 따른다.
