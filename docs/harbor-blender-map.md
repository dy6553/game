# 항구 Blender 모델 반영

항구 화면에 Blender의 전체 맵을 불러온다. 높음은 고화질 모델을 사용하며, 균형과 낮음은 텍스처 없는 모델을 공유한다. 낮음과 자동 절전에서는 저부하 재질을 적용한다. 자동의 높은 화질 전환은 기존 성능 판단을 따른다. 선택한 모델만 요청하며 다음 모델을 장면에 붙인 뒤 이전 모델을 해제한다. 불러오기에 실패하면 화면에 이미 있는 맵을 계속 표시한다.

Blender 모델은 건물 16동, 엄폐물 10개, 문 6개를 포함한다. 새 문은 기존 문 상태에 따라 움직인다. 항구에서 출입 가능한 6동의 2층 베란다는 출입구 쪽 한 면 전체에 있다. 옥상은 바깥으로 튀어나오는 발코니 대신 네 면을 펜스로 둘렀다. 두 펜스는 0.65m이고 걸어서 통과할 수 없으며 점프로 넘을 수 있다. 펜스와 바닥의 위치는 모델과 이동·사격 판정에서 일치한다. 폐공장은 기존 구조와 외형을 사용한다.

| --- | ---: | ---: | ---: |
| 낮음·균형 | 1.42 MB | 18,832 | 53 |
| 높음 | 7.07 MB | 95,452 | 290 |

모델·텍스처는 프로젝트용으로 Blender에서 만들었다. 낮음의 창틀·차양은 정점 색으로 표현하고, 높음의 벽돌·목재·노면은 웹용 텍스처와 게임 조명으로 표현한다. 간판은 Blender 기본 글꼴을 메시로 변환했고 모델에 외부 파일 참조가 없다.

- [x] 로컬 웹·서버 빌드, 문과 사격 판정, 6동의 베란다 바닥과 옥상 네 면 펜스를 검증했다.
- [x] 서버와 같은 이동 계산으로 2층과 옥상 펜스가 걷기를 막고 점프를 허용하는지 확인했다.
- [x] 로컬 Chromium에서 낮음 → 높음 → 낮음 전환에 따른 파일 요청을 검증했다.
- [ ] 모든 주요 동선에서 외형과 판정 사이의 어긋남을 실제 플레이로 확인한다.
- [ ] 저사양·고사양 실제 기기에서 로딩, 발열, 프레임 시간을 측정한다.
