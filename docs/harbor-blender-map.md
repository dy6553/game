# 항구 Blender 모델 반영

높음은 예전 항구를 그리던 건물, 보도, 화단과 조명 경로를 복구했다. 균형과 낮음은 텍스처 없는 Blender 모델을 공유한다. 낮음과 자동 절전에서는 저부하 재질을 적용한다. 높음으로 전환하면 Blender 모델을 해제하고 기존 외형과 그림자를 복원한다. Blender 파일을 불러오기에 실패하면 기존 외형을 표시한다.

Blender 모델은 건물 16동, 엄폐물 10개, 문 6개를 포함한다. 새 문은 기존 문 상태에 따라 움직인다. 항구에서 출입 가능한 6동의 2층 베란다는 출입구 쪽 한 면 전체에 있다. 옥상은 바깥으로 튀어나오는 발코니 대신 네 면을 펜스로 둘렀다. 두 펜스는 0.65m이고 걸어서 통과할 수 없으며 점프로 넘을 수 있다. 펜스와 바닥의 위치는 모델과 이동·사격 판정에서 일치한다. 폐공장은 기존 구조와 외형을 사용한다.

낮음은 남보라색 하늘과 보도, 청록색 외벽, 호박색 창을 사용한다. Blender에서 만든 화단, 차양, 보도를 정점 색으로 표현하며 외부 파일 참조가 없다.

실내등은 문턱에서 서서히 밝아지고 층 높이에 따라 이동한다. 직접 조명과 번쩍이는 반사를 줄이고, 반복 줄무늬가 강하던 바닥·계단은 대비가 낮은 작은 목재 텍스처로 바꿨다. 옥상에는 실내등을 적용하지 않는다. 상점 앞 보도의 창빛은 기존 반사 메시 묶음에 넣었다.

계단 가장자리의 이동과 바닥 지지가 같은 폭 기준을 쓴다. 계단 쪽으로 조금 비껴서 걸어도 발판에 닿으면 점프 없이 다음 층으로 올라갈 수 있다.

로컬 Chromium에서 상점가, 부두, 외곽 골목, 남쪽 거리의 높음 화면이 기존 렌더 경로와 같은 카메라에서 픽셀 단위로 일치하는지 비교했다. 낮음은 앞선 검증에서 네 구역의 프레임당 그리기 요청이 50, 41, 29, 48회로 공개 버전과 동일했고, 화면 삼각형은 약 5–7% 늘었다. 실기기 FPS는 아직 측정하지 않았다.

- [x] 로컬 웹·서버 빌드, 문과 사격 판정, 6동의 베란다 바닥과 옥상 네 면 펜스를 검증했다.
- [x] 서버와 같은 이동 계산으로 2층과 옥상 펜스가 걷기를 막고 점프를 허용하는지 확인했다.
- [x] 로컬 Chromium에서 낮음 → 높음 → 낮음 전환에 따른 파일 요청을 검증했다.
