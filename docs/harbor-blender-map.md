# 항구 Blender 모델 반영

항구 화면에 Blender의 전체 맵을 불러온다. 높음은 고화질 모델을 사용하며, 균형과 낮음은 텍스처 없는 모델을 공유한다. 낮음과 자동 절전에서는 저부하 재질을 적용한다. 자동의 높은 화질 전환은 기존 성능 판단을 따른다. 선택한 모델만 요청하며 다음 모델을 장면에 붙인 뒤 이전 모델을 해제한다. 불러오기에 실패하면 화면에 이미 있는 맵을 계속 표시한다.

Blender 모델은 건물 16동, 엄폐물 10개, 문 6개를 포함한다. 새 문은 기존 문 상태에 따라 움직인다. 출입 가능한 건물의 2층·옥상 발코니 바닥과 개구부를 기존 월드 치수에 맞췄다. 기존 충돌 메시와 월드 데이터는 계속 이동, 사격, 봇 경로와 서버 판정을 담당한다. 폐공장은 기존 외형을 사용한다.

모델·텍스처는 프로젝트용으로 Blender에서 만들었다. 간판은 Blender 기본 글꼴을 메시로 변환했고 모델에 외부 파일 참조가 없다.

- [x] 로컬 웹 빌드, 문 열기와 사격 판정, 6동의 2층·옥상 발코니 바닥과 출구를 검증했다.
- [x] 로컬 Chromium에서 낮음 → 높음 → 낮음 전환에 따른 파일 요청을 검증했다.

- [ ] 저사양·고사양 실제 기기에서 로딩, 발열, 프레임 시간을 측정한다.
