# 생존 자동 난이도 — 2026-11-06

## 확정한 범위

사용자가 자동 난이도 추천안을 승인하고 갑작스러운 변화를 완화하도록 요청했다. 추가 질문에서 9단계 보간을 승인했다. 이번 자동 선택은 웨이브 생존에만 적용한다. 총20웨이브·생명3개이며 매 경기5단계(기존 보통)에서 시작한다. 계정 레벨·실력 등급·영구 저장과 연동하지 않는다.

- 체력50 이상으로 두 웨이브 연속 완료하면 다음 웨이브 준비 진입 시1단계 올린다.
- 체력50 미만으로 완료하면 연속 성공 횟수를 초기화한다.
- 사망 즉시 난이도를 바꾸지 않는다.3초 뒤 같은 웨이브 재도전 시1단계 내리고 연속 횟수를 초기화한다.
- 최저1, 최고9이며 한 번에 한 단계만 변한다. 최종 승리/패배 뒤에는 바꾸지 않는다.
- 웨이브 중 봇과 증원의 난이도는 유지한다. 새 웨이브/재도전에서 생성되는 봇에 적용한다.

## 화면과 구조

홈 → 봇 대전 → 웨이브 생존 → 난이도 ‘자동 · 생존 9단계’. 경기 중 HUD에 ‘자동 5/9’ 형태로 표시한다. 생존 외 모드에서는 자동 옵션을 숨기고 비활성화하며, 자동에서 다른 모드로 바꾸면 보통을 선택한다. 재시작 시5단계로 초기화한다. 기존 고정 난이도는 유지한다. 서버·서비스·로그 수집을 추가하지 않는다.

조정 계산부는 명시적인 정책을 입력받으며 상태를 외부에서 직접 바꾸지 않는다. 기존 봇 전투 엔진에 자동 전용 보간 프로필을 주입한다. 고정 난이도의 기존 동작은 같은 프로필을 사용한다.
