# 하단 6칸과 맞춤 조작

하단 슬롯은 무기 3칸·수류탄·섬광탄·회복키트의 한 줄 6칸이다. 기존 무기 선택/교체·장비 사용과 개수 표시를 재사용한다. 문/획득 안내는 별도 영역에 두고 앉기/엎드리기는 중앙 위쪽으로 옮겨 문·획득·점프 버튼과 구분한다.

환경설정 → 조작 → 조작 맞춤설정에서 키보드 18개 동작을 변경한다. 동작 선택 후 키 변경 버튼을 누르고 문자·숫자·스페이스·Shift·방향키를 지정한다. 충돌하면 두 동작의 키를 교환한다. Esc는 취소하며 브라우저 조합키는 지정하지 않는다. 마우스 사격은 기존대로다. 문/장비/자세/무기 슬롯 표시에도 변경한 키를 반영한다.

화면의 이동·발사·재장전·점프·확대·달리기·대시·앉기·엎드리기·하단 6칸·문·획득의 위치와 크기를 슬라이더로 조절하고 미리본다. 설정은 별도 브라우저 저장소에 저장하며 화면 회전/리사이즈 때 재배치한다. 크기는 60~150%, 위치는 0~100%이다. 조작만 기본값 복원은 게임 기록을 지우지 않는다. 전체 환경설정 초기화도 조작을 초기화한다. 사용자 배치끼리의 겹침은 사용자가 조절한다.

TDD: 맞춤 키 변환/영구 저장과 터치 위치 저장 누락으로 실패함을 확인한 후 구현했다. 중복 교환·오래된 키 해제·좌표/크기 범위·초기화·기존 점프 설정 이전·저장 실패 처리를 검증했다. 기존 입력/터치 검사와 빌드 통과. Chromium 1280×800 터치 환경에서 실제 V키 앉기, C키 해제, 새로고침 후 키/위치 저장, 한 줄 6개 슬롯과 오류 없음 확인. 1280×800 및 844×390에서 자세 버튼과 문/획득/점프/재장전 버튼의 비겹침을 검사했다. 실제 삼성 인터넷 기기에서 손가락 조작 체감은 별도 확인이 필요하다.

장비의 기본 키는 하단 순서에 맞춰 수류탄4·섬광탄5·회복키트6이다. 이전 G/B/H 기본 설정은 새 기본 키로 이전하고 별도로 변경한 키와 화면 배치는 유지한다. 새 기본값에서는 이전 G/B/H도 보조 키로 사용할 수 있지만, 해당 키를 다른 동작에 지정하면 지정한 동작이 우선한다.

사용자의 정면 시야 가림 보고에 따라 기본 자세 버튼은 왼쪽 가장자리로 옮겼다. 이전 버전에 저장된 중앙 영역의 자세 버튼 배치만 한 번 기본 위치로 되돌리고, 다른 키·버튼 배치는 유지한다. 이후 사용자가 다시 설정한 위치는 그대로 저장한다.
