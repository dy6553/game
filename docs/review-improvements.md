# 웹 검토 후 수정 — 2026-11-06

사용자가 오류·개선 추천 전체 적용을 요청했다. 무기 획득/3개 소지/교체는 보류를 유지한다.

## 적용한 동작

- 이동과 전투·재장전·점프를 같은 시간 단위로 진행한다. 보통 프레임은 전부 반영하고 25ms 이하로 분할한다. 250ms를 넘는 긴 정지는 모든 규칙에 동일한 상한을 적용한다. 10FPS에서 이동만 절반으로 느려지던 차이를 제거했다.
- 마우스 고정용 더블클릭을 없애고 PC 전용 시작/고정/계속 버튼을 제공한다. 고정 실패 시 드래그 조준으로 계속할 수 있다. 고정 해제는 일시정지로 이어진다.
- 다시 시작 시 승패·체력·부활·재장전·발걸음·빈 탄창 효과음 추적값을 초기화한다.
- 도움말에 닫기 버튼을 제공하고 Esc로 닫는다. 현재 무기의 탄창·재장전 안내 및 접근성 이름을 표시한다. 페이지 제목과 설명도 봇 대전·표적 연습에 맞췄다.
- 시작 화면에서 캐릭터·모드·무기를 함께 선택한다. 경기 중 다시 열 때 현재 설정을 표시하며 모드/무기를 바꾸고 시작하면 새 경기가 된다.
- 메뉴·도움말에는 일시정지 안내/계속하기, 창 전환·마우스 고정 해제에는 별도 일시정지 화면을 제공한다. 정지 중 이동·조준·발사 입력을 막고 복귀 시 눌린 입력을 이어받지 않는다.
- 시안 비교는 도움말의 개발용 도구로 이동하고 비교 화면에 별도의 복귀 버튼을 제공한다.
- 모바일 조준 감도 0.25~2배를 제공하고 브라우저에 저장한다. PC 마우스 감도에는 영향을 주지 않으며 저장이 차단돼도 플레이할 수 있다.
- 임시 성능 표시는 실제 렌더 해상도, 최근 최대 10초 평균 FPS, P95 프레임 시간, 50ms 초과 프레임 수를 보여준다. 대기/일시정지 구간은 제외한다. FPS 향상 실측을 주장하지 않는다.

## 검증

- `npm run build`: 타입 검사 및 웹 프로덕션 빌드 통과. 기존 대형 JS 청크 알림은 남는다.
- `npm test`: 42개 통과. 10/60FPS의 이동 거리·재장전 동등성, 긴 정지 상한, 프레임 통계, 정지 입력 차단·감도·더블클릭 동작을 추가 검증했다.
- 별도 DOM 대역 검사: PC/모바일 입력 조건 각각 통과. 실제 main.ts의 시작 설정·시간 처리·도움말/비교 닫기·일시정지/복귀·감도 저장·명시적 고정·재경기 효과음을 검사했다.
- DOM 대역은 Engine/장면/오디오를 대체한다. 실제 WebGL 화면, 버튼 겹침, 브라우저의 Pointer Lock 허용, 실기기 멀티터치·음향·FPS·발열을 검증한 것은 아니다.

## DOM 검사 재현

선택 검사 도구인 LinkeDOM 0.18.12(MIT)를 임시 폴더에 설치한다. 게임 의존성/배포 번들에는 추가하지 않았다.

```sh
npm install --prefix /tmp/harbor-dom-qa --ignore-scripts linkedom@0.18.12
HARBOR_DOM_MODULE=/tmp/harbor-dom-qa/node_modules/linkedom/esm/index.js node docs/qa/ui-flow.mjs
HARBOR_DOM_MODULE=/tmp/harbor-dom-qa/node_modules/linkedom/esm/index.js node docs/qa/ui-flow.mjs --mobile
```

실제 기기에서는 같은 화질·같은 장소·같은 이동 경로로 10초 이상 비교한다. 먼저 시작 설정, 이동+조준+발사 동시 터치, 도움말 닫기, 앱 전환 후 계속하기, PC 고정 성공/거부/해제, 재경기 승패음을 확인한다.
