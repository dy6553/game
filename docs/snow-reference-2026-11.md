# 설산 참고 이미지 개선 — 2026-11-17

사용자가 승인한 둥근 연구기지·밝은 실내·중앙 엄폐 기둥·낮/밤과 오로라를 구현한다. 낮과 밤은 각각 약 40~80초 사이의 결정적 난수로 전환을 시작하며 6초 동안 부드럽게 바뀐다. 시작 시 낮이고, 온라인에서는 기존 서버 경기 시간과 시드로 동일한 시간대를 계산한다. 일시정지한 오프라인 경기는 시간이 멈춘다. 기존 랜덤 폭설 주기·10초 예고·28m 시야와 봇 탐지 제한은 유지한다.

공통 기하에 중앙 기둥을 추가하고 기존 양옆 기둥을 제거한다. 기둥의 보이는 본체와 사격/이동 장애물은 동일한 사각 단면이다. 공통 구조 버전은 igloo-v3이며 다른 버전의 설산 클라이언트는 새로고침 안내를 받는다. 주변에 충분한 우회 공간을 확보하며 표적 연습의 시작점을 x=3으로 옮겨 첫 표적이 기둥에 가려지지 않도록 한다. 맵 전환 후 일반 재시작과 거리별 표적 연습도 해당 맵의 시작점을 사용한다. 외관과 밝은 바닥·벽, 따뜻한 등, 청록색 기둥 띠는 불투명 메시로 기존 배치에 합친다. 오로라는 하늘 꼭짓점 색으로 표현하며 추가 광원·입자나 대형 투명면을 사용하지 않는다. 하늘 색 갱신은 0.5초 간격이다.

동물 종류·고기 효과는 이전 질문의 답변이 아직 없어 추가하지 않는다. 실제 삼성 인터넷 GPU·프레임·발열은 클라우드 Chromium 소프트웨어 렌더링 결과와 구분한다.

TDD: 중앙 기둥과 랜덤 시간대 검사에서 기존 구현의 누락으로 먼저 실패했고, 구현 후 우회 동선·사격 차폐·동일 시드 재현성과 전환을 통과했다. 중앙 기둥으로 인해 기본 표적 사선이 막히는 검사를 추가해 실패를 확인한 뒤 설산 시작점을 조정했다. 기존 천장 사격과 입구 테스트는 새 기둥을 피하는 실제 동선으로 갱신하며 판정 비교와 출입 검사는 유지한다.
