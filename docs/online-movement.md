# 온라인 이동 지연·끊김 개선 — 2026-11-06

사용자가 실제 플레이에서 지연과 이동 버벅임을 보고했다. 기존 내 카메라는 서버의 20Hz 위치를 프레임마다 그대로 사용해 50ms 단위 위치 계단과 왕복 지연이 화면에 드러나는 구조였다. 실제 기기 FPS·RTT는 아직 수집하지 않았으므로 모든 원인을 이 구조 하나로 확정하지 않는다.

## 변경

- 입력한 수평 이동을 매 렌더 프레임 즉시 예측한다. 서버와 같은 속도·달리기 조건·벽 충돌·캐릭터 반경을 사용한다.
- 서버가 확인한 입력 번호를 기준으로 미확인 입력을 재적용한다. 작은 오차는 시각적 오프셋을 서서히 줄여 보정하고, 3m 이상 오차·부활·대기/연결 끊김은 서버 위치로 초기화한다.
- 0.5초 이상 상태가 오지 않으면 예측 이동을 멈춘다. 재연결 뒤에는 서버 상태를 다시 기준으로 삼는다.
- 상대의 회전은 짧은 각도 방향으로 보간하고 점프 높이도 프레임 사이를 연결한다.
- 입력 전송 누적 시간의 잔여분을 유지해 60FPS 환경에서 전송이 20Hz보다 낮아지던 문제를 줄인다. 긴 프레임 뒤 입력을 한꺼번에 보내지 않는다.
- 온라인 모드 버튼의 disabled 상태는 실제 변경될 때만 갱신한다.

피해·탄약·점수·승패와 실제 위치는 계속 서버가 확정한다. 점프 자체의 입력 예측·총격 판정 지연 보상·서버 지역 변경은 이번에 도입하지 않았다. 인터넷 왕복 시간을 없애거나 특정 FPS를 보장하지 않는다.

## 검증

자동 검사 57개, 타입·프로덕션 빌드, Worker dry-run, PC/모바일 DOM 검사 통과. 새 이동 검사 4개는 첫 응답 전 반응, 100ms 왕복 지연/20Hz 상태에서 프레임별 연속 이동·정지 후 수렴, 사망/부활/패킷 단절, 공통 경계 충돌을 확인한다. 가상 60FPS/100ms 테스트에서 프레임 이동 상한은 0.25m 미만이며 기존 20Hz 위치 계단은 걷기 기준 0.35m였다. 이는 실제 휴대폰 측정치가 아니다.

실제 두 기기에서 새로고침 후 이동/멈춤/벽 접촉과 상대 회전·점프를 확인하고, 남는 문제는 내 화면 전체의 낮은 FPS인지 온라인 위치 되돌림인지 구분해 기록한다.
