# UI·총기 소리·길 안내 개선

사용자가 추천 항목 4(UI), 5(총기별 소리), 6(전장 길 안내)을 요청했다.

## UI

하단 6칸의 실루엣 아이콘·키 번호·이름·수량을 같은 카드 구조로 표시한다. 선택 무기는 금색 테두리/하단 띠, 빈 슬롯과 사용할 수 없는 장비는 낮은 강조로 구분한다. 체력·탄약·미니맵 패널의 배경·테두리·숫자 표현을 맞춘다. 기존 키 지정, 사용 동작, 화면 위치/크기 설정과 6칸 구성을 유지한다. SVG는 직접 작성했고 외부 이미지/폰트가 추가되지 않는다.

## 소리

9종 무기의 공격음·저음 몸통·금속성 잔음·감쇠 길이를 다르게 만든다. 기존 4종 CC0 샘플은 새 서명 음색과 혼합하고, 다른 무기는 합성 버퍼를 사용한다. 초기 해제 시 버퍼를 준비하고 디코딩된 샘플이 도착하면 캐시를 갱신한다. 발사마다 필터/오실레이터를 추가하지 않는다. 기존 24개 효과음 한도, 중요 소리 우선순위, 거리 감쇠/좌우, 음소거/음량/앱 비활성 처리 유지. 환경설정 → 사운드 → 총기 소리 미리듣기에서 비교할 수 있다. 미리듣기는 이전 미리듣기를 중단해 중첩을 제한한다.

## 길 안내

항구의 출입 가능 건물 6동은 A1~A6, 공장 4동은 F1~F4 코드를 사용한다. 이름·색·코드는 입구 표식, 계단 끝 2F/옥상 RF 표식, 미니맵에 공통으로 연결한다. 미니맵 아래 현재 건물·층수를 표시하며 실외는 구역 이름을 표시한다. 안내는 현재 자기 위치와 정적 건물 정보만 사용한다. 기존 적 탐지·층간 사격·이동·충돌은 바꾸지 않는다.

표식 전체는 공유 1024px 텍스처 한 장과 불투명 묶음 메시 하나로 구성하고, 광원·그림자·충돌·피킹을 추가하지 않는다. 낮음 맵 모델로 전환해도 표식을 유지한다. 입구 표식은 처마 아래 문 옆, 층별 표식은 계단 끝 벽/옥상 가장자리에 배치한다.

## 검증

TDD에서 무기 소리의 에너지/유일성, 건물 코드·층수 누락, 아이콘 누락을 먼저 실패로 확인했다. 파형의 유한성·피크·끝 감쇠, 9종 차이, 두 맵의 코드 일관성·발코니 위치, 단일 표식 묶음과 비충돌을 자동 검사한다. 기존 오디오/온라인 오디오·건물/장면 회귀도 검사했다. Chromium 터치 1280×800에서 9종 미리듣기 재생, 6칸 아이콘·버튼 영역, 층별 위치 표시, 표식 비피킹과 페이지 오류 없음을 확인했다.

실제 삼성 인터넷·Intel GPU의 FPS 및 스피커/이어폰별 청취 체감은 측정하지 않았다. 시각·음색의 주관적인 완성도는 실제 플레이 후 추가 조정할 수 있다.
