# PC 마우스 시점 수정 — 2026-11-08

사용자가 ‘컴퓨터로 하는데 화면이 마우스를 안 따라감’이라고 보고했다.

## 원인과 변경

기존 PC는 드래그하거나 메뉴의 마우스 고정을 눌러야 했다. 고정 상태에서도 canvas pointermove에만 의존해 표준 Pointer Lock의 document mousemove만 전달되는 환경에서는 시점이 움직이지 않을 수 있었다.

- 플레이 화면을 왼쪽 클릭하면 마우스 고정을 요청하고 ‘화면을 클릭해서 마우스로 조준’ 안내를 표시한다. 홈/모달/일시정지/전환 중에는 고정을 요청하지 않는다.
- 첫 클릭은 조준 활성화만 수행하고 발사/자동사격을 큐에 넣지 않는다. 고정 후 클릭부터 기존처럼 발사한다.
- 고정 상태는 document mousemove의 movementX/Y로 회전한다. canvas pointermove에서 같은 물리 이동을 중복 적용하지 않는다.
- Esc/고정 해제 시 일시정지하는 기존 동작을 유지한다. ‘계속하기’는 드래그 조준으로 돌아가고, ‘마우스 고정 후 계속’ 또는 메뉴 고정으로 재활성화한다. 새 경기에는 클릭 고정을 다시 제공한다.
- Promise 거절/동기 실패뿐 아니라 구형 pointerlockerror 이벤트에서도 실패 안내·복구 경로를 제공한다.
- 모바일은 기존 드래그/이동/발사 동시 터치를 유지하며 고정을 요청하지 않는다. 무기/점프/피해/서버 규칙 변경 없음.
