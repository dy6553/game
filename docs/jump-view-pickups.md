## 구현

카메라 updateUpVectorFromRotation을 켜 매 시점 변경에서 위 방향을 다시 계산한다. 기존 시각 반동의 회전/피치가 남아 다음 드래그의 수평선을 기울이는 문제를 막는다. 반동 설정은 유지한다.

온라인 점프는 최신 서버 높이/속도에서 수신 사이 시간을 최대150ms까지 적분해 높이를 매 프레임 표시한다. 점프 물리·피해·부활 규칙은 바꾸지 않는다.

공통 inventory.ts가 소지/탄창/재사용 대기시간/상자 상태를 관리한다. 시작 위치 앞쪽(0,-4) 기관총, 동쪽(8,0) 산탄총, 서쪽(-8,0) 저격총, 북쪽(0,12) 권총 상자. 빛나는 상자는 사격·이동 장애물이 아니다. 접근하면 이름과 획득 버튼이 나온다. 최대3개 시 아래 슬롯이 버릴 총 선택으로 바뀌고 취소할 수 있다. 탄약·재장전 상태·재사용 대기시간은 교체 후에도 유지하며 한 번의 시간 단계에서 한 번만 진행한다. 점수·체력·매치는 무기 교체로 초기화하지 않는다. 사망 시 선택한 시작 총만 복구하며 경기/연습을 새로 시작하면 상자와 인벤토리를 초기화한다.

온라인 입력에 pickup/replace/slot을 추가하고 서버가 위치·상자 상태·중복·한도·사망·종료 여부를 검증한다. 기존 저장 상태는 inventory/pickups/startWeapon을 복구 시 보완한다. 클라이언트가 재고를 자체 확정하지 않는다. 서버 구버전에는 상자 조작을 비활성화한다.
