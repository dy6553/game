# 캐릭터와 무기 외형 개선

2026-11-11: 로봇 캐릭터에 가슴 장갑, 칼라, 정강이 금속 장식과 코어 렌즈를 추가하고 1인칭 무기와 로비 무기의 레일과 측면 패널을 개선했다. 외부 에셋이나 추가 동적 조명은 사용하지 않는다. 1인칭 장식은 재질별로 합치며 로비 무기는 기존 재질별 병합을 유지한다. 다인전 원격 모델은 기존 경량 형상을 유지한다. 충돌, 무기 수치와 서버 규칙은 변경하지 않았다.

프로덕션 빌드 성공. 실제 화면의 심미적 품질과 저사양 기기 GPU 사용량 및 FPS는 측정하지 않았다.
검증: 전체 314개 검사 중 원격 장식 비교 실패를 수정한 뒤 관련 검사 10개가 통과했다. 부활 좌표의 fallSpeed 필드 관련 3개 실패는 변경 전 e871eb5에서도 동일하게 재현된다. 전체 검사를 수정 후 재실행하지 않았으며 나머지 기존 실패를 임의로 해결하지 않았다.
