# 전투 보조 기능 — 2026-11-13

사용자가 추천 1~4번 적용을 요청하고 5번 계정별 환경설정 동기화를 제외했다. 계정·저장 구조와 무기 피해량, 헤드샷 배율, 단발 즉사 방지 규칙을 변경하지 않는다.

- 연습장 현황의 **거리·이동 표적** 버튼: 기존 배치 또는 출발점 전방 10/20/40m 선상에 세 표적을 배치한다. 이동 설정은 기존 메시의 루트만 좌우로 이동한다. 실제 피격 메시·미니맵 위치·체력 막대가 함께 움직인다. 적용 시 출발점/자세/탄약/표적을 초기화하며, 일시정지 중에는 움직이지 않는다. 봇전·온라인에서는 연습 설정을 적용하지 않는다.
- 온라인 팀전 미니맵의 **아군 핑**: 적 발견/이동/지원 선택 후 큰 지도의 위치 또는 내 위치를 선택한다. 수동 위치 표시이며 적 탐지 기능이 아니다. 서버가 종류와 유한 좌표/맵 범위, 생존/참가 여부를 검증한다. 한 사람당 하나, 1.5초 간격, 6초 유효, 최대 20개다. 공유 패킷에서 핑을 제거하고 수신자별로 아군 핑만 추가한다. 최초 welcome과 구형/신형 통신 모두 필터링한다. 20Hz 전송은 유지한다.
- 로비/게임 메뉴의 **무기 비교**: 실제 WEAPONS/거리 감쇠 규칙에서 9종의 몸통·머리 피해, 산탄 수, 탄창, 발사 간격, 재장전, 감쇠 시작을 계산한다. 거리 슬라이더 0~100m. 산탄은 탄환 하나 기준, 점사는 내부 간격과 점사 간격을 구분한다. 바주카 머리 배율 없음, 직격 최대치임을 명시한다. 봇전 강화 수치 제외.
- 몸통/헤드샷/처치/부활 보호 명중의 문구·색·표식을 구분한다. 온라인 보호 표시는 서버가 확인한 광선 명중에만 포함하며, 피해/처치로 표시하지 않는다. 봇 헤드샷 판정도 표시로 전달한다. 대화상자에서 전투 입력을 멈추고 기본 포커스/Tab/Escape를 지원한다. 온라인 상대의 경기는 계속된다.
