# 무기 피해 조정

체력 100, 헤드샷 1.5배를 유지한다. 권총 22, 기관총 11, 기관단총 8, 산탄총 탄환당 15(6개), 저격총 70, 3점사 17, 4점사 16, 반자동 소총 42, 바주카 직격 110이다. 바주카 폭발의 거리 감쇠와 장비·아군 피해 규칙은 기존 그대로다. 봇 강화는 기존대로 기본 피해에 적용된다.

기준은 역할 분리와 이전보다 여유 있는 대응 시간이다. 반자동 소총의 몸통 2발 처치를 없앴고, 산탄총은 몸통 전탄 90으로 한 번에 처치하지 못한다. 저격총은 몸통 2발, 헤드샷 1발이다. 반자동 무기의 실제 발사 성공률, 산탄 명중 개수, 온라인 서버 20Hz, 머리 판정, 상대 이동과 네트워크 지연 때문에 이론상 처치 시간은 실전 결과가 아니다.

검토 근거: [Riot의 거리별 무기 비교](https://playvalorant.com/en-us/news/dev/valorant-data-drop-phantom-vs-vandal/), [EA 무기 종류 안내](https://help.ea.com/en/articles/apex-legends/guns-and-weapons/), [EA 밸런스와 실제 경기 데이터](https://www.ea.com/games/apex-legends/apex-legends/news/30-1-designers-notes). 타 게임의 수치를 그대로 옮기지 않았다.

TDD: 새 무기 수치 및 서버 반자동 소총 피해 테스트가 기존 수치에서 실패함을 확인한 뒤 구현했다. 서버 저격총 몸통·헤드샷 검사를 추가했고 기존 수치에 의존하던 테스트를 갱신했다. 실제 기기와 플레이어 간 거리별 명중률·승률은 검증하지 않았다. 총탄은 별도 거리별 피해 감소가 없고 온라인 발사 간격은 20Hz에 의해 달라질 수 있어 향후 실전 데이터에 따른 추가 조정이 필요하다.

## 한 발 처치 방지 — 사용자 추가 요청

체력 100에서는 한 발(산탄은 발사 1회 전체 탄환 포함)로 사망하지 않도록 저격총 55/헤드샷 82.5, 산탄총 9×6/모두 머리 명중 시 81, 바주카 직격 80으로 변경했다. 봇전 최대 강화 15%에서도 각각 94.875/93.15/92로 100 미만이다. 헤드샷 1.5배는 유지한다. 체력이 이미 감소한 상대의 마무리 처치 및 여러 발을 발사하는 점사는 별도다. 수류탄은 이번 총탄 조정 대상에 포함하지 않는다.

TDD: 기존 코드에서 산탄 전탄 머리 명중 135 피해 및 서버 저격 헤드샷 즉사로 실패하는 것을 확인한 뒤 수정했다. 서버 저격 생존·바주카 직격 생존, 실제 장면 무기·재장전 관련 검사 11개가 통과했다.
