# 경기 결과와 브라우저 개인 전적 — 2026-11-06

사용자가 결과 화면·최근 경기·최고 기록·같은 설정 재도전과 홈 이동을 승인했다. 저장은 로그인 없이 현재 브라우저의 localStorage에 한정한다. 새로운 서비스·서버 저장·계정 정보를 추가하지 않는다.

## 완료한 동작

- 봇1대1·봇3명 개인전·웨이브 생존·온라인1대1에서 승패가 확정되면 결과 창을 연다. 표적 연습과 중도 종료는 전적에 넣지 않는다.
- 결과는 승패·처치·사망·경기 시간을 표시한다. 생존은 도달 웨이브와 해당 경기 최고 자동 난이도를 추가 표시한다.
- 개인전 사망은 세 봇의 처치 합계, 생존 사망은 소모 생명, 온라인 사망은 서버 상태의 상대 처치 수다.
- 봇전 ‘같은 설정으로 다시 하기’는 선택한 모드·난이도·캐릭터·시작 총을 유지하며 새 경기로 초기화한다. 자동 난이도는 기존 규칙대로5/9로 초기화한다.
- 온라인은 재경기 합의 프로토콜이 없으므로 ‘새 온라인 경기’로 표시하고 선택한 총·캐릭터를 유지한 로비로 돌아간다. 상대를 자동으로 재경기에 넣지 않는다.
- 홈의 ‘개인 전적’에서 최근20경기, 누적 경기/승패, 고정 난이도별 생존 최고 웨이브와 최고 자동 단계를 확인한다. 최근 목록에서 오래된 경기가 빠져도 누적/최고 수치는 유지한다.
- 결과 창과 기록 창은 작은 가로 화면에서도 스크롤한다. 모달 역할·제목·버튼 포커스·Tab 순환과 기록 창 Escape 닫기를 제공한다. 결과 중 이동/사격/획득/슬롯/확대를 차단한다. 승패 효과음은 결과 화면에서도 재생하고 비활성 창에서는 멈춘다.

## 시간·저장 기준

오프라인 경기 시간은 실제 시뮬레이션 진행 시간이다. 준비/사망 대기는 포함하고 메뉴·설정·일시정지·비활성 창은 제외한다. 온라인은 두 플레이어가 연결된 상태에서 관찰한 서버 tick 차이(50ms)를 합산한다. 상대가 경기하는 동안 내 메뉴를 연 시간은 포함하며 대기/관찰된 연결 복구 구간은 제외한다. 접속 중단 직전/직후 일부 간격은 관찰할 수 없으므로 공식 서버 경기 시간으로 주장하지 않는다.

`src/results.ts`는 완료 여부·경기 ID·시간·최고 단계를 추적하고, JSON 입력 검증·최대20개 목록·누적/최고 통계·ID 중복 방지·저장 실패 처리를 담당한다. `src/results-view.ts`는 표시와 버튼 동작만 담당하고 `main.ts`가 실제 전투/온라인 상태를 연결한다.

localStorage 키는 `harbor-match-results-v1`. 저장 항목은 임의 생성한 로컬 경기 ID, 종료 시각, 모드·난이도, 승패·처치·사망·시간, 생존 웨이브/최고 단계다. 온라인 방 코드·토큰·서버 플레이어 ID·이름·좌표·입력은 저장하지 않는다. 수정 가능한 기기 개인 기록이며 공식 순위/계정 전적이 아니다. 브라우저 데이터 삭제 시 사라지고 다른 기기와 공유되지 않는다.

경기 ID는 새 경기/새 온라인 세션에서 만들고 재접속에는 유지한다. 종료 상태 반복 수신/완료 프레임 반복/최근 저장 기록 재로드 시 중복을 막는다. 여러 탭의 동시 저장에 대한 트랜잭션이나 서버 공식 결과 ID 기반 중복 방지는 범위에 없다. 저장 제한/권한 예외는 메모리 기록으로 대체하고 저장 실패를 표시한다. 손상·미지원 저장 형식은 읽지 못한 것으로 처리하며 실행을 중단하지 않는다.
