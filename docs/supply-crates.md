# 보급 상자 외형 개선 — 2026-11-06

사용자는 다음 단계 추천과 함께 상자를 더 고급스럽게 바꾸도록 요청했다. 다음 기능으로 웨이브 생존을 추천했고 이번 작업은 상자 표현에 한정한다.

## 표현

모서리를 깎은 짙은 금속 몸체/뚜껑, 은색 모서리 보강재, 고무 받침과 뚜껑 실링, 황동 잠금장치, 뒤쪽 힌지와 측면 통풍구를 조합했다. 전면 총기 실루엣은 실제 선택 무기의 형태에 따라 권총/기관총/산탄총/저격총으로 구분한다. 무기별 청록/민트/주황/보라 표시등과 미세 표면 질감을 적용했다. 반사는 기존 조명의 StandardMaterial specular 표현이며 실시간 환경 반사를 추가하지 않았다.

비어 있는 상자도 케이스를 남겨 보급 위치를 알 수 있게 한다. 대기 중 표시등은 어두워지고 전면 주황색 막대가 차오른다. 접근 HUD에는 남은 초와 비활성 ‘재보급 대기’ 버튼을 표시한다. 20초가 지나면 무기 색 표시와 획득 버튼으로 돌아온다. 데이터는 기존 pickups.remaining을 읽으며 실제 타이머/획득 규칙을 별도로 계산하거나 변경하지 않는다.

## 성능·범위

4개 상자만 생성하고 정적 부품을 재질별로 병합한다. 정적 월드 행렬은 동결하고 충전 막대만 변형한다. 고정 상자당7개 메시(6개 정적 묶음+충전 막대)와 공유 재질·64px 표면 텍스처를 사용한다. 별도 조명/파티클/새 후처리/외부 에셋/유료 서비스는 없다. 시간 경과나 재시작에 메시·재질을 생성하지 않는다. 모든 상자 부품은 사격 비대상이며 이동 충돌 데이터도 바꾸지 않는다.

## TDD와 검증

먼저 tests/supply-visuals.test.ts를 실행했다. 첫 결과1개 실패/1개 통과: 획득 후 빈 케이스가 사라져 재보급 위치를 표시할 수 없었다. UI 역시 대기 상자를 숨겨 재보급 시간을 안내하지 못하는 단언이 실패했다. 구현 후 두 검사와 UI가 통과했다. 반복 획득/초기화에서 메시·재질 개수 유지, 비대상 유지, 미리보기에서 숨김, 기존 획득 제한을 확인한다.
