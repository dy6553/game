# 3D 캐릭터 중심 출격 로비 — 2026-11-07

사용자가 ‘타사 게임 로비처럼’ 변경을 요청했다. 특정 게임의 에셋이나 화면을 복사하지 않고 상용 슈팅 게임에서 익숙한 캐릭터 중심 구성과 가장자리 메뉴 배치를 이 게임에 적용했다.

## 화면과 동작

- 중앙에 실제 게임의3D 로봇을 항구 배경과 함께 표시한다. 기존 평면 캐릭터 SVG 미리보기와 큰 설정 패널을 제거했다.
- 상단은 플레이/캐릭터/장비/개인 전적 메뉴, 좌측은 현재 캐릭터·시작 무기, 우측 하단은 모드·난이도·큰 게임 시작 버튼이다.
- 캐릭터·무기 메뉴를 누르면 기존 게임 내 카드 선택창에서 고른다. 두 로봇/네 무기, 생존 자동 제한, 온라인 로비 전달과 기존 경기 규칙을 유지한다.
- 로비는 별도 스크롤 없이 가로 화면의 가장자리에서 조작하고, 캐릭터가 중앙에 보이도록 비네트와 반투명 패널을 사용한다. 작은 가로 터치 화면은 항구 소개 타일을 접고 장비/출격을 유지한다.

## 실제 모델 미리보기

`scene.setPreview(true,true)`는 기존 게임 모델/받침/미리보기 조명을 재사용하는 로비 구도다. 마지막 경기 위치가 벽/실내였더라도 캐릭터·카메라는 공통 시작 지점에 놓는다. 게임 시뮬레이션 위치를 수정하지 않으며 전투는 정지한다. 게임 시작 시 원래1인칭 카메라와 FOV로 돌아간다. 기존 경기 중 캐릭터 준비창의 미리보기는 기존 구도를 유지한다.

새 캐릭터 모델/조명/메시 풀/외부 이미지/라이브러리/서비스를 추가하지 않는다. 선택 시 기존 모델 교체 방식을 사용하고, 로비 반복 진입만으로 메시/재질 수를 늘리지 않는다. 계정 레벨·화폐·상점·배틀패스 등 새 시스템을 추가한 것으로 표시하지 않는다.
