# 전투·자세·발코니 변경

사용자는 바주카 개선, 수류탄 아군 피해, 총기 밸런스, 앉기/엎드리기, 옥상 탈출과 2층/옥상 발코니, 고층 사격의 지도 표시·알림을 요청하고 전체 변경 후 기존 서비스 배포를 승인했다. 헤드샷 배율은 사용자 확인으로 1.5배다.

## 피해와 무기 역할

| 무기 | 몸통 피해 | 머리 피해 | 설명 |
|---|---:|---:|---|
| 권총 |25|37.5|최소 발사 간격 0.25초|
| 기관총 |12|18|초당8발, 중거리|
| 기관단총 |8|12|초당12발, 탄퍼짐|
| 산탄총 |12×6|18×6|탄환별 판정|
| 저격총 |80|120|몸통2발, 머리1발|
| 반자동 소총 |50|75|몸통2발|
| 3점사 |18×3|27×3|짧은 점사|
| 4점사 |15×4|22.5×4|4발 점사|
| 바주카 |직격120|추가 배율 없음|폭발6m, 거리 감쇠, 재장전3초|

온라인은 서버가 피해·위치·피격 자세·승패를 판정한다. 봇 대전에서는 실제로 맞은 머리 메시로 배율을 적용한다. 표적 연습판에는 머리 판정이 없다. 수류탄은 아군과 자신에게 피해를 주며 아군 처치로 킬/팀 점수를 얻지 않는다. 총탄과 바주카의 아군 면역, 벽 차폐, 부활 보호는 유지한다.

## 자세와 건물

C/앉기 버튼, Z/엎드리기 버튼으로 전환하고 같은 조작으로 선다. 앉기 속도55%, 엎드리기25%다. 눈높이와 서버 피격 높이, 원격 자세 표시를 연결한다. 엎드림은 누운 모델의 방향으로 피격 상자를 회전한다. 서 있지 않은 자세에서는 달리기·점프·대시를 시작할 수 없다.

두 맵의 출입 가능한 건물에 2층·옥상 발코니를 추가한다. 중앙 개구부로 나가 가장자리를 벗어나면 중력으로 지상에 내려온다. 이번 변경에는 별도 낙하 피해가 없다. 바닥/출구의 렌더링과 사격/이동 충돌을 함께 변경한다.

2층 높이 이상의 사격은 상대 미니맵에 4초간 위치를 드러내고 알림을 표시한다. 본인에게도 노출 알림을 표시한다. 지도 표시는 조준 대상의 벽 차폐 판정을 바꾸지 않는다. 봇 고층 사격에도 지도 표시와 알림을 적용한다.

## 그래픽과 검증

이전에 준비해 둔 선명도 설정도 포함한다. 자동 해상도 하한과 낮음 설정을0.7로 높여0.35~0.45에서의 흐려짐을 줄인다. GPU 비용과 선명도 사이의 선택이며 실기기FPS 향상을 보장하지 않는다. 실패했던 공간 분할 배칭 실험은 포함하지 않는다.

TDD에서 몸통/머리 피해, 수류탄 아군 피해, 바주카 거리 피해의 실패를 확인한 뒤 수정했다. 두 맵 발코니 이동/중력, 자세 검증/속도/피격 높이, 고층 사격 노출·벽 차폐 검사를 추가했다. Chromium에서C/Z 눈높이와20인 장면, 페이지 오류 없음도 확인했다. 최종 전체 회귀/빌드 및 배포 결과는 완료 응답과 실행 로그를 따른다. 테스트 브라우저는SwiftShader이며 사용자 Intel GPU의FPS는 측정하지 않았다.
