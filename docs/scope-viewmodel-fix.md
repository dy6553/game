# 이동 중 저격총 확대·축소 / 1인칭 총 잘림 수정

2026-11-07 사용자 보고: 저격총을 들고 이동할 때 확대·축소가 되지 않고 총 뒷부분이 깨져 보인다. 기존 저격총 배율·피해·이동·탄약 규칙은 바꾸지 않는다.

## 입력 수정

모바일 확대 버튼은 `click`에만 연결되어 있었다. 이동 스틱·시점 조작을 누른 상태에서 합성 click이 오지 않아도 사용할 수 있게 `pointerdown`에서 바로 처리한다. 이후 발생하는 일반 click은 무시해 두 번 토글하지 않는다. 키보드·보조 입력의 `detail=0` click과 PC Q키는 유지한다. 이동·시점 포인터를 reset하거나 해제하지 않는다.

PC와 터치가 같은 실행 조건을 사용한다. 홈·대화상자·일시정지·비활성 화면에서는 작동하지 않고 온라인은 생존·경기 진행·연결 상태를 확인한다. 온라인 HUD에서 이전 모드의 disabled 상태가 남지 않도록 갱신하고 `aria-pressed`를 실제 확대 상태와 맞춘다. 확대/축소가 실제로 바뀐 경우만 효과음을 재생한다.

## 총 표시 수정

카메라에 붙은 총과 손이 주변 건물·가구와 같은 깊이 버퍼에 그려지고 있었다. 가까운 구조물이 총 일부를 가르는 경로를 없애기 위해 월드를 그린 뒤 깊이를 초기화하고 1인칭 총·손을 별도 렌더링 그룹으로 그린다. 총 부품 사이의 깊이 비교는 유지한다. 별도 카메라나 추가 모델은 만들지 않는다.

적·로비 총은 기존 월드 렌더링을 유지한다. 사격 광선·벽 충돌·명중 판정은 바꾸지 않는다. 확대 중 총 숨김·축소 후 복구·로비 미리보기에서 1인칭 총 숨김도 유지한다.

이 변경은 월드 깊이에 의한 잘림을 처리한다. 사용자가 본 모든 그래픽 증상을 동일하게 재현했다거나 실제 Android 화면을 검사했다고 주장하지 않는다. 수정 배포 후 동일 장면의 기기 확인이 남는다.
