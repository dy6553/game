# 이글루 접합부·실내·랜덤 폭설 — 2026-11-17

## 사용자 요청과 배포 상태

입구 위 빈틈, 연구동 끝벽 색상 깜빡임, 실내 외형을 수정한다. 폭설은 고정 주기 대신 시작과 지속시간을 랜덤으로 정하고 시작 전에 남은 초를 표시한다. 가까운 곳은 선명하고 먼 곳은 가린다.

사용자가 2026-11-17 확인 답변으로 맑음 40~80초, 폭설 총 20~35초, 시작 10초 전 예고를 확정했다. 총 폭설 시간에는 강해지는 4초와 걷히는 6초를 포함한다. 기존 웹과 온라인 서버에 함께 배포한다.

## 구조 수정

- 중앙 돔의 사각 개구부와 아치 사이 빈 모서리를 공유 곡면 조각으로 채운다. 출입구 중심의 서서 이동·사격은 열려 있다.
- 연구동 끝벽을 계단형 직육면체에서 지붕과 같은 16분할 곡선의 단면으로 교체한다. 사격과 화면이 같은 꼭짓점을 사용한다.
- 터널은 접합 벽면에서 시작하며 접합면의 중복 뚜껑과 지붕 안쪽의 끝벽 상면을 그리지 않는다. 끝벽에는 옛 사각 건물용 가로 띠를 생성하지 않는다.
- 이웃 곡면 사이의 숨은 공통 면도 그리지 않는다. 저사양 외형 예산은 기존 12,000삼각형 미만을 유지한다.
- 실내의 줄눈 대비를 줄이고 밝은 벽 패널, 따뜻한 천장 띠·바닥 유도선, 연구대 화면·상판과 밝은 기둥을 기존 불투명 배치에 합친다. 추가 동적 조명·투명 효과·텍스처는 없다.
- 구조 리비전을 `igloo-v2`로 올린다. 서버·클라이언트 버전 검사와 저장된 구형 위치 복구는 기존 경로를 사용한다.

## 기상 동기화와 표시

서버가 경기마다 한 번 만든 `weatherSeed`와 경기 시간 `weatherTime`으로 다음 맑음 길이와 폭설 길이를 계산한다. 두 프로토콜과 재접속·체크포인트에 같은 시드를 전달한다. 오프라인은 경기 재시작 때 시드를 다시 고르며 테스트에서는 고정 시드를 주입한다. 매 프레임 새 난수를 뽑지 않고 이미 계산한 기상 구간을 재사용한다.

예고 구간에는 화면 위쪽 중앙의 상태 카드 아래에 `폭설까지 N초`를 표시한다. 미니맵을 꺼도 이 예고는 보이며 설정·홈 등 전투 HUD가 비활성이면 숨긴다. 미니맵 상태란에는 폭설 중 남은 지속시간도 표시한다.

강한 폭설은 모든 그래픽에서 14m까지 선명하고 14~28m는 점차 안개로 가려진다. 28m 밖 봇 탐지와 적 접촉 표시도 제한한다. 저사양·눈 입자 끄기로 공통 시야 제한을 없앨 수 없다.
