# 사격 임팩트 — 2026-11-06

사용자가 추천한 우선 조합인 무기별 반동·로봇 피격 반응·처치 연출과 화면 흔들림 조절을 승인했다.

## 구현

- 권총: 짧고 날카로운 반동. 기관총: 작은 반동을 연속 적용하고 누적 상한을 둔다. 산탄총·저격총: 강한 뒤밀림과 비교적 느린 복귀. 총기 모델의 반동은 무기별로 다르며, 카메라에는 작은 롤·화각 변화만 적용한다. 입력 조준의 좌우/상하 방향을 밀거나 피해·탄약·발사 간격을 바꾸지 않는다.
- 로봇 피격: 실제 맞은 지점에 금속/전기 불꽃을 생성하고 몸통을 짧게 흔든다. 로봇 전용 재질 복사본으로 순간적인 피격 빛을 표시하므로 내 캐릭터의 재질은 바뀌지 않는다.
- 처치: 눈과 발광부를 약0.16초 동안 끄고 약0.55초 동안 기울여 쓰러뜨린다. 작은 파편과 연기가 발생하며, 약1.15초 후 모델을 숨긴다. 죽은 직후부터 사격 판정에서 제외한다. 기존3초 부활과10킬 승리 규칙은 그대로다.
- 도움말의 화면 흔들림에서 끄기/약하게/보통을 선택한다. 기본은 약하게이며 브라우저에 저장한다. 끄기는 카메라 흔들림과 화각 변화를 없애고 총기 자체 애니메이션은 유지한다.
- 새 이펙트는 고정32개 풀(불꽃24·파편6·연기2)을 재사용한다. 균형/모바일 화질은 한 번에 최대16개를 사용한다. 일반 피격은2~4개, 불꽃0.18~0.4초·파편0.7초·연기0.85초로 제한한다. 모두 사격/이동 판정에서 제외하고 조명·실시간 반사를 추가하지 않는다.
- 일시정지 중 반동·피격/처치 애니메이션을 멈춘다. 캐릭터 선택/시안 비교에서는 떠 있는 이펙트를 제거하고 경기 재시작·봇 부활 때 자세와 재질을 복원한다.

`src/impact.ts`: 무기별 반동·흔들림. `src/robot-impact.ts`: 로봇 피격·처치·고정 이펙트 풀. `scene.ts` 연결, `main.ts` 설정. 새 외부 에셋·서비스·패키지는 추가하지 않았다.

## 검증과 제한

- 타입·웹 프로덕션 빌드 통과.
- `npm test`:45개 통과. 반동 구분/누적 제한/시간별 복귀/흔들림 끄기, 재질 격리, 반복 피격 시 메시·재질 수 고정, 파편 판정 제외, 처치 시 표시/판정/점수/부활, 일시정지 및 화면 전환 정리를 검사한다.
- PC/모바일 조건의 DOM 대역 흐름 검사에서 설정 변경·저장을 포함한 기존 흐름 통과.
- NullEngine·DOM 대역은 실제 GPU 화면과 실기기 검증이 아니다. 실제 기기에서 반동 강도·로봇 쓰러짐·조준점/탄착 느낌·멀티터치·프레임·발열을 확인해야 한다.
- 재질별 벽 탄착 분류나 화면 전체 피해 맥동은 이번 우선 조합에 포함하지 않았다. 기존 탄착·피격 방향·명중/처치 표시와 효과음은 유지한다.
