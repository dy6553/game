시작 화면에서 캐릭터·모드·무기를 함께 고릅니다. 메뉴·도움말·창 전환에는 일시정지와 계속하기를 제공하고 정지 중 입력을 차단합니다. 도움말에서 모바일 조준 감도(브라우저 저장)를 조절하며, 시안 비교는 개발용 도구에서 엽니다. 현재 무기에 맞춘 재장전 안내와 도움말 닫기 버튼을 제공합니다.
