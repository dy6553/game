# 항구의 밤 — 웹 버전

## 봇 3명 개인전 — 2026-11-06 사용자 확정

나와 봇3명, 총4명이 각자10킬을 경쟁하는 모드를 구현했다. 사용자는 세부 선택에서 ‘봇은 플레이어만 공격’을 선택했다. 따라서 봇끼리 싸우지 않는다. 봇3명은 선택한 동일 난이도/권총, 체력100·3초 부활을 사용하며 부활은 살아 있는 캐릭터들과 가장 먼 충돌 없는 후보 지점에서 한다. 무적 시간은 추가하지 않는다. 플레이어는 기존 무기 상자/3개소지/시작 총 부활을 유지한다. TDD 및 자동80개·PC/모바일 DOM 검증은 [봇3명 개인전](docs/bot-group.md)을 따른다. 실제 기기 프레임·조작·난이도 체감은 별도 확인한다.


## 봇 난이도 확장 — 2026-11-06 사용자 승인

봇1대1의 쉬움·보통·어려움을 구현했다. 승인 수치: 쉬움 기존 조준1초/경고0.4초/이동3 유지, 보통0.7초/0.35초/이동4, 어려움0.45초/0.3초/이동5. 보통·어려움은 조준 중 좌우 이동하고 발사 경고 중 멈춘다. 모든 난이도는 체력100·피해25·3초 부활·10킬, 권총 탄약/재장전과 최소 발사 간격0.8초를 유지한다. 시작 화면/메뉴에서 선택하고 변경 시 새 경기, 재시작 시 선택 유지. TDD Red→Green 및 자동74개 검증은 [봇 난이도](docs/bot-difficulty.md)를 따른다. 개인전·웨이브 생존·자동 난이도·성장은 후속이다.


## 점프·시점 수정 및 무기 획득 재개 — 2026-11-06

사용자가 점프 떨림·드래그 후 기울어짐 수정과 무기 획득을 요청했고 추천 세부 규칙을 승인했다. 이전 무기 획득 보류를 해제한다. 보급 상자 근처2.5m에서 PC E/획득 버튼, 최대3개·1~3/슬롯 교체, 가득 차면 버릴 슬롯 선택, 중복 획득 불가, 상자20초 후 재생성(경기 진행 시간), 버린 총 제거, 사망 시 선택한 시작 총만 복구한다. 온라인은 거리·소지·재생성·교체·부활을 서버가 확정한다. 자동70개와 빌드/DOM 검사, TDD 실패→통과 기록은 [점프·시점·보급 기록](docs/jump-view-pickups.md)을 따른다. 실제 GPU/휴대폰 체감 확인은 별도다.


## 공개 온라인 연결 — 2026-11-06

웹 https://project-3uu6s.vercel.app 에 공개 서버 https://game.yuni100106yuni.workers.dev 를 연결했다. Vercel production VITE_ONLINE_URL 설정 및 재배포 완료. 공개 서버에 실제 WebSocket 2개를 연결해 방 생성·입장·정원 제한·잘못된 Origin 차단·서버 판정 처치·재접속·나가기·자동 매칭을 통과했다. 실제 기기 간 플레이/GPU/네트워크 체감 검증은 남는다. 루트 wrangler.jsonc로 Cloudflare가 정적 웹 대신 서버 코드를 배포하도록 수정했다.



## 웹 검토 수정 — 2026-11-06

시작 화면에서 캐릭터·모드·무기를 함께 고릅니다. 메뉴·도움말·창 전환에는 일시정지와 계속하기를 제공하고 정지 중 입력을 차단합니다. 도움말에서 모바일 조준 감도(브라우저 저장)를 조절하며, 시안 비교는 개발용 도구에서 엽니다. 현재 무기에 맞춘 재장전 안내와 도움말 닫기 버튼을 제공합니다.

낮은 FPS에서도 이동과 전투가 같은 시간 기준으로 진행되도록 수정했고, 재경기 효과음 상태를 초기화합니다. 임시 HUD는 평균 FPS·실제 렌더 해상도·P95·끊김을 표시합니다. 실제 기기의 성능 개선은 아직 측정하지 않았습니다.

자세한 변경과 검증·DOM 검사 재현 방법: [웹 검토 수정 기록](docs/review-improvements.md).
