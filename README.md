# 항구의 밤 — 웹 버전

## 경기 결과·브라우저 개인 전적 — 2026-11-06 사용자 승인

봇전/생존/온라인 승패 확정 시 결과 화면, 같은 설정 재도전(온라인은 로비 복귀), 홈 개인 전적을 추가했다. 최근20경기와 누적 승패·난이도별 생존 최고 웨이브·최고 자동 단계를 현재 브라우저에 저장한다. 중도 종료/표적 연습은 제외한다. 로컬 경기 ID로 종료 반복/재접속 중복을 방지하고 저장 실패 시 메모리 기록과 안내를 제공한다. 방 코드/토큰/서버플레이어ID는 저장하지 않는다. 범위/시간/한계/TDD는 [경기 결과](docs/match-results.md)를 따른다. 로그인·공식 서버 전적·계정 성장은 후속이며 이번 기록은 기기 개인 기록이다.


## 자동 난이도 9단계 — 2026-11-06 사용자 승인

웨이브 생존에 자동 난이도를 추가했다. 총20웨이브·생명3개·5/9단계 시작이며, 체력50 이상으로2웨이브 연속 완료하면1단계 상승하고 사망3초 후 재도전 시1단계 하락한다.1~9 범위에서 조준/경고/이동/좌우이동을 보간하고 전투 중에는 유지한다. 고정 난이도는 기존대로다. HUD 단계 표시·다른 모드 자동 차단·재시작 초기화와 TDD/검증은 [자동 난이도](docs/adaptive-difficulty.md)를 따른다. 계정 실력 등급 연계 및 봇1대1/개인전 자동 난이도는 후속이다.


## 웨이브 생존 — 2026-11-06 사용자 승인

생존 모드를 구현했다. 생명3개, 쉬움10/보통20/어려움30웨이브, 첫 적3명·2웨이브마다1명 증가·최대12명·동시최대3명이다. 첫 시작과 웨이브 사이5초 준비 및 체력/모든 소지 총 탄창 회복, 사망3초 후 현재 웨이브의 적/상자/체력/탄약을 초기화하고 시작 총만 복구한다. 마지막 웨이브 클리어 승리·생명 소진 패배이며 추가 무적은 없다. 기존 난이도/무기/상자를 재사용한다. TDD 및 전체91개/타입빌드/PC·모바일 DOM 검증은 [웨이브 생존](docs/survival.md)을 따른다. 실제 GPU/휴대폰 체감 검증은 별도다.


## 보급 상자 외형 개선 — 2026-11-06

사용자 요청으로 단색 상자를 모서리 절단 금속 케이스·보강 프레임·힌지·잠금장치·무기 실루엣·무기별 발광색으로 바꿨다. 재보급 대기 중 케이스를 유지하고 충전 막대와 남은 시간을 표시한다. 획득/거리/소지/교체/20초 규칙은 유지한다. 추가 조명·파티클 없이 부품을 재질별로 합쳐 고정 생성한다. TDD 상태 전환 검사와 전체82개/빌드/PC·모바일 DOM 검증은 [상자 외형](docs/supply-crates.md)을 따른다. 실제 GPU/실기기 외형 평가는 별도다. 다음 기능 추천은 웨이브 생존이며 이번 변경에는 포함하지 않는다.


## 봇 3명 개인전 — 2026-11-06 사용자 확정

나와 봇3명, 총4명이 각자10킬을 경쟁하는 모드를 구현했다. 사용자는 세부 선택에서 ‘봇은 플레이어만 공격’을 선택했다. 따라서 봇끼리 싸우지 않는다. 봇3명은 선택한 동일 난이도/권총, 체력100·3초 부활을 사용하며 부활은 살아 있는 캐릭터들과 가장 먼 충돌 없는 후보 지점에서 한다. 무적 시간은 추가하지 않는다. 플레이어는 기존 무기 상자/3개소지/시작 총 부활을 유지한다. TDD 및 자동80개·PC/모바일 DOM 검증은 [봇3명 개인전](docs/bot-group.md)을 따른다. 실제 기기 프레임·조작·난이도 체감은 별도 확인한다.


## 봇 난이도 확장 — 2026-11-06 사용자 승인

봇1대1의 쉬움·보통·어려움을 구현했다. 승인 수치: 쉬움 기존 조준1초/경고0.4초/이동3 유지, 보통0.7초/0.35초/이동4, 어려움0.45초/0.3초/이동5. 보통·어려움은 조준 중 좌우 이동하고 발사 경고 중 멈춘다. 모든 난이도는 체력100·피해25·3초 부활·10킬, 권총 탄약/재장전과 최소 발사 간격0.8초를 유지한다. 시작 화면/메뉴에서 선택하고 변경 시 새 경기, 재시작 시 선택 유지. TDD Red→Green 및 자동74개 검증은 [봇 난이도](docs/bot-difficulty.md)를 따른다. 개인전·웨이브 생존·자동 난이도·성장은 후속이다.


## 점프·시점 수정 및 무기 획득 재개 — 2026-11-06

사용자가 점프 떨림·드래그 후 기울어짐 수정과 무기 획득을 요청했고 추천 세부 규칙을 승인했다. 이전 무기 획득 보류를 해제한다. 보급 상자 근처2.5m에서 PC E/획득 버튼, 최대3개·1~3/슬롯 교체, 가득 차면 버릴 슬롯 선택, 중복 획득 불가, 상자20초 후 재생성(경기 진행 시간), 버린 총 제거, 사망 시 선택한 시작 총만 복구한다. 온라인은 거리·소지·재생성·교체·부활을 서버가 확정한다. 자동70개와 빌드/DOM 검사, TDD 실패→통과 기록은 [점프·시점·보급 기록](docs/jump-view-pickups.md)을 따른다. 실제 GPU/휴대폰 체감 확인은 별도다.

## 웹 검토 수정 — 2026-11-06

시작 화면에서 캐릭터·모드·무기를 함께 고릅니다. 메뉴·도움말·창 전환에는 일시정지와 계속하기를 제공하고 정지 중 입력을 차단합니다. 도움말에서 모바일 조준 감도(브라우저 저장)를 조절하며, 시안 비교는 개발용 도구에서 엽니다. 현재 무기에 맞춘 재장전 안내와 도움말 닫기 버튼을 제공합니다.

낮은 FPS에서도 이동과 전투가 같은 시간 기준으로 진행되도록 수정했고, 재경기 효과음 상태를 초기화합니다. 임시 HUD는 평균 FPS·실제 렌더 해상도·P95·끊김을 표시합니다. 실제 기기의 성능 개선은 아직 측정하지 않았습니다.

자세한 변경과 검증·DOM 검사 재현 방법: [웹 검토 수정 기록](docs/review-improvements.md).

무기별 반동, 로봇 피격 반응과 처치 시 쓰러짐·전기 불꽃·파편·연기를 추가했습니다. 도움말에서 화면 흔들림을 끄기/약하게/보통으로 조절하며 기본은 약하게입니다. 설정은 브라우저에 저장합니다. 기존 피해·탄약·부활·승리 규칙은 유지합니다. 빌드 및 자동45개, PC/모바일 DOM 대역 검사 통과. 실제 GPU/휴대폰 검증은 남아 있습니다. [구현·검증 기록](docs/combat-impact.md).
