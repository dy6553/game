# 항구의 밤 — 웹 버전

## 공개 온라인 연결 — 2026-11-06

웹 https://project-3uu6s.vercel.app 에 공개 서버 https://game.yuni100106yuni.workers.dev 를 연결했다. Vercel production VITE_ONLINE_URL 설정 및 재배포 완료. 공개 서버에 실제 WebSocket 2개를 연결해 방 생성·입장·정원 제한·잘못된 Origin 차단·서버 판정 처치·재접속·나가기·자동 매칭을 통과했다. 실제 기기 간 플레이/GPU/네트워크 체감 검증은 남는다. 루트 wrangler.jsonc로 Cloudflare가 정적 웹 대신 서버 코드를 배포하도록 수정했다.


## 홈·온라인 최신 상태 — 2026-11-06

홈 화면과 봇/표적 연습 진입, 사람 간 1대1 클라이언트 및 Cloudflare Durable Objects 서버를 구현했다. 사용자 추천 구성 승인에 따른 작업이다. 자동 검사49개·빌드 및 로컬 실제 WebSocket 2개 검증을 완료했다. Cloudflare 인증이 없어 공개 온라인 서버 연결은 미완료이며 현재 웹에서는 준비 중으로 안내한다. 실제 기기 검증은 남는다. 상세 상태와 무료 한도·연결 방법은 [홈 및 온라인 대전](docs/home-online-plan.md)을 따른다.


실행: https://project-3uu6s.vercel.app

Babylon.js + TypeScript + Vite로 만든 1인칭 로봇 슈팅 시제품입니다. 권총·기관총·산탄총·저격총, 표적 연습과 쉬운 봇1대1, 모바일 터치, 스페이스바 점프, 재장전, 사운드와 음량 설정을 제공합니다.

단일HTML 다운로드 및 HTML뷰어 대응 빌드는 종료했습니다. 2MB 단일 파일 검사를 제거하고 JavaScript·CSS·오디오를 분리해 웹으로 배포합니다. 웹페이지 진입점 index.html은 웹 실행에 필요합니다. 모바일 성능·네트워크·호스팅 무료 사용량은 계속 고려합니다.

```sh
npm ci
npm run build
npm test
```

PC: WASD 이동, 드래그 시점, 클릭 발사, 스페이스 점프, R재장전, Q저격 확대. 별도의 마우스 고정 버튼 또는 ‘마우스 고정하고 시작’으로 조준하며 기관총 연사가 가능합니다. Esc는 고정 해제와 일시정지입니다. 휴대폰 가로: 스틱·드래그·발사·점프·재장전. 메뉴에서 시작 무기를 바꾸면 새 경기를 시작합니다. 도움말에서 음량과 화질을 조절합니다.

온라인 사람 간 대전은 서버 공개 연결 전입니다. 대시·무기 획득/소지·나머지 AI모드·계정·전적은 미구현입니다. Neon은 초기화 후 인증 시간 초과로 실제 서비스 연결과 검증이 남아 있습니다. 자동 검사42개 및 PC/모바일 DOM 대역 흐름 검사 통과 기록과 실제 모바일/GPU/청취 검증은 구분합니다.

CC0 Kenney 효과음 및 자체 합성음 사용. public/audio의 라이선스와 docs/audio.md 참조. 런타임 라이선스는 public/THIRD_PARTY_RUNTIME_LICENSES.txt에 포함합니다.

## 웹 검토 수정 — 2026-11-06

시작 화면에서 캐릭터·모드·무기를 함께 고릅니다. 메뉴·도움말·창 전환에는 일시정지와 계속하기를 제공하고 정지 중 입력을 차단합니다. 도움말에서 모바일 조준 감도(브라우저 저장)를 조절하며, 시안 비교는 개발용 도구에서 엽니다. 현재 무기에 맞춘 재장전 안내와 도움말 닫기 버튼을 제공합니다.

낮은 FPS에서도 이동과 전투가 같은 시간 기준으로 진행되도록 수정했고, 재경기 효과음 상태를 초기화합니다. 임시 HUD는 평균 FPS·실제 렌더 해상도·P95·끊김을 표시합니다. 실제 기기의 성능 개선은 아직 측정하지 않았습니다.

자세한 변경과 검증·DOM 검사 재현 방법: [웹 검토 수정 기록](docs/review-improvements.md).

## 사격 임팩트

무기별 반동, 로봇 피격 반응과 처치 시 쓰러짐·전기 불꽃·파편·연기를 추가했습니다. 도움말에서 화면 흔들림을 끄기/약하게/보통으로 조절하며 기본은 약하게입니다. 설정은 브라우저에 저장합니다. 기존 피해·탄약·부활·승리 규칙은 유지합니다. 빌드 및 자동45개, PC/모바일 DOM 대역 검사 통과. 실제 GPU/휴대폰 검증은 남아 있습니다. [구현·검증 기록](docs/combat-impact.md).
